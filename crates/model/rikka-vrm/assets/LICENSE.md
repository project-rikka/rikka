# LICENSE file for the model: avatar.vrm

`avatar.vrm` is the VRM Consortium's sample avatar `VRM1_Constraint_Twist_Sample`, taken
unmodified from <https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample>.

* (c) 2022 pixiv Inc.
* Licensed under the [VRM Public License 1.0](https://vrm.dev/licenses/1.0/).

The license settings the file itself carries permit redistribution and modification, allow
use as an avatar by anyone, and ask for no credit:

* `avatarPermission`: `everyone`
* `commercialUsage`: `corporation`
* `allowRedistribution`: `true`
* `modification`: `allowModificationRedistribution`
* `creditNotation`: `unnecessary`

The model is shipped for the tests and the example that read it.
