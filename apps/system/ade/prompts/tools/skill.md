Loads a listed skill's instructions and the inventory of its supporting files. Load a skill before doing work it matches, none when none matches, and each at most once; never claim a skill you did not load.

- Supporting files are listed, not read, with paths relative to the skill folder. Read or run one only when the skill says to.
