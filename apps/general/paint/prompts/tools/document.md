+++
name = "Document"

[params]
document = "Tab name; the active tab when omitted. Every Paint tool takes it."
+++

Lists the window's tabs (size, depth, colour mode, profile, format, unsaved or never saved), then for the tab: layers top first (index, name, kind, Background, hidden, opacity, blend) with their objects top first (id, kind, place, colours), the chosen layer that changes go to by default, the selection (bounds, pixels, soft edges), an open dialog and the latest history.
