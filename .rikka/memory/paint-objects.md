---
title: Paint editable objects (figures)
description: Session-only shape/text objects above a layer's pixels: Figure model, overlays, edits, GUI picking, the assistant.
about: apps/general/paint
tags: [paint, objects]
---

- The figure model lives in the shared `rikka-figure` (`crates/graphics/rikka-figure`; overlay painting and on-canvas typing in `crates/ui/rikka-figure-editing`): `Form` (Line/Arrow with `Pen`, `Shape { shape, frame, look }`, `Path(PathMark)`, `Text(Lettering)`), `Frame`, `Look { fill, outline }`, `Affine`, `Typeset`, `figure::recipe` (text as vector glyph outlines), `Grips`/`Manipulation`, overlay painting (`paint_grips`, `paint_band`, `paint_loop`) and on-canvas typing (`Typing`, `text_with_preedit`). Paint imports these directly; paint-document does not re-export them.
- `paint-document/src/figure.rs` keeps only Paint's identity layer: `Figure { id: FigureId, form: Form }`, `FigureIds`, and `FigureKind` (tool mapping: `of(FormKind)`, `form_kind()`, `spanned(from, to, pen, style)`, which always gives lines their pen even under the Fill filling). Paint draws only `Shape::Rectangle { radius: 0 }` and `Shape::Ellipse`; other shapes map to `FigureKind::Rectangle`.
- psd geometry maps reach figures as `figure::Affine::from_array(map.to_array())`; `figure::Error` maps onto Paint's `Error::UnknownFont`/`Unlettered`.
- `FigureIds` is one shared `Arc<AtomicU64>` allocator: the worker reports it in `Report::Opened`, the tab and the assistant composer allocate from it; `FigureEdit::Add` refuses ids already used.
- Objects are session-only: saving and every reader see baked pixels; nothing is written into files.
- `State.overlays` (`overlay.rs`) maps a layer key (psd `lyid`, given on first object; `PLAIN` = 0 for a plain picture) to `Overlay { base, figures, linear }`; the layer record/picture always holds `base` + figures baked, so composite, thumbnails, sampling, merging and saving need no special case.
- Writers go through the base: `develop` on an overlaid layer runs `develop_overlaid` (raster edits land beneath objects), previews render base + recipe + figure steps, histograms read the base; crop/reshape/convert `refit` bases and map figures (text and everything under it is pressed into the base on turn/flip/rotate); layer restructures carry overlays (`Carried`: copied with fresh ids on duplicate, dropped on merges, made transparent on Layer from Background). `Overlays` holds `Arc<Overlay>` so whole-map swaps are cheap; `State::overlay` charges history only for entries that changed or left.
- Edits: `Edit::Figures { layer, change: FigureEdit::{Add{by: AddMethod}, Change{by: FigureChange}, Remove, Stack(StackOrder), Rasterize} }`, recorded as `Action::Figure(FigureAction)` with one `Swap::Overlays` plus the layer swap; `Document::preview_figures(layer, figures, scale)` shows a layer with a replaced object list.
- GUI (`src/figures/`, `canvas/figures.rs`, `canvas/frames.rs`, `tab/figuring.rs`, `paint/figuring.rs`): `Tool::Objects` (V) and the shape tools pick objects across visible pixel layers; `FigureSelection` (Observed) holds ids, the live drag and the settling copy; Paint's thin `figures::Manipulation` applies the shared `figure::Manipulation`'s `Reach` to `Figure`s (text scales only when a single text is resized by a side grip; `Ended` reshapes a single line/arrow); drags and options-bar sliders/colour wells preview through `Tab::lift` (worker figure preview) and commit one edit on release.
- Picking adopts the object's colours and options (`figures::adopted`); changing options while objects are picked restyles them (`Restyle`, pending previews settle on the next pick change). A fill-only shape has no outline width; switching it to an outlined filling takes the options bar's width.
- Commands: `Command::Object(Objecting)` (cut/copy/paste via an in-process clipboard, duplicate, delete, stack, rasterize), `Command::Clear` (Delete: objects first, else erase selection); the canvas context menu lives in `workspace.rs`. Text objects reopen with the Text tool or a double-click (`Typing::edit`, `Draft.editing`).
- Assistant: Draw's line/arrow/rectangle/ellipse/path/text items become objects (ids in the answer), Document lists objects under their layers, and `Paint_Objects` moves, rotates, sets, deletes, arranges, duplicates and rasterizes by id.
