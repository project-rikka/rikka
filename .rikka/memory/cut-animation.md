- `animation/`: `Track<K: Kind>` (a `rikka_keyframe::Sequence<Key<K>>` plus cached legs and bases) over markers `Scalar` (f32), `Planar` (non-spatial `Point`), `Spatial` (position: keys carry `Bend` tangents) and `Chroma` (`Color`, travelled in OKLab + linear alpha). `Key { at, value, timing: Timing { incoming, outgoing, smooth }, bend }`; `Outgoing::{Hold, Linear, Bezier(Handle), Preset(Preset)}`, `Incoming::{Linear, Bezier}`, `Handle { speed (units/frame along travel), influence }`, `Smooth::{Manual, Continuous, Auto}`.
- Every mutation re-settles the track, which also caches each segment's `Leg` and the graph bases, so sampling never rebuilds routes: Auto speeds (neighbour Catmull-Rom, influence ⅓) and Auto spatial tangents are recomputed, Continuous keys get equal speeds / opposed tangents. Overlapping influences are shared out at evaluation only; a Linear side is a chord handle at ⅓.
- A segment is a cubic in (frame, travel): scalars travel by value, others by distance (arc length for curved spatial routes, straight lines otherwise). `Preset { easing, from, to }` is a slice of a Penner `rikka_keyframe::Easing { family, ease }` so crops stay exact; a degenerate slice gets one extra key.
- Read through `Clip::channel(&Property) -> Channel<'_>` (typed refs): `sample`, `speed`, `graph_value`/`spans` (value graph; multi-dim = cumulative distance), `handle_toward` (graph point → `Handle`), `Track<Spatial>::path()`; `Clip::holds(&KeyRef)` / `Clip::interpolation(&KeyRef)` answer for one key, and `Interpolation::{PLAIN, EASY}` list the menu choices.
- `Property::{Placement(PlacementField), Art(ArtField), Camera(CameraField), Mix(MixField), Effect { slot, knob }}`; non-effect tracks live in the private `Motion` map keyed by `property::Field`; base values stay in the source (`Clip::base`/`rebase`). The private `Animated` trait (Placement, Art, Camera, Mix) drives sampling and Redraw absorption. `Project::keyable(clip, property)` decides what a clip may key (Mix needs sound, Camera a camera, the rest a picture); `Clip::is_animated` counts every track, `Clip::is_moving` only picture-changing ones (the renderer's cue).
- Edits: `Edit::Key` (`KeyChange::{Add, Remove, Clear, Value, Handle, Smooth, Bend}`), `Edit::Keys { keys: Vec<KeyRef>, change: KeysChange::{Move, Duplicate, Delete, Interpolate} }`, `Edit::KeyGroup` (all of `Clip::grouped()`), `Edit::PasteKeys` (from `Project::copy_keys`), `Edit::AnimationPresets`. All share `Clip::keyed`, which lends a property's track and base to one closure. Crops (trim/split/retime) go through `animation/crop.rs` and freeze Auto keys next to the cut.
- `tween.rs`: a simple motion (`Clip::tween() -> Option<Tween { start, end, easing }>`, timeline frames) is not stored: it is derived whenever every keyed placement field (camera field for cameras) has exactly two keys, at local 0 and length − 1, the first with `Outgoing::Preset`. `Edit::Tween { clip, change: TweenChange::{On, Off { at }, Ease, Reverse} }` builds, flattens, re-eases or mirrors those tracks (`animation/tween.rs` does the per-track work). While a clip tweens, Redraw on an end frame keys that end (a still field gains a two-key track), elsewhere or with an anchor change it shifts both ends; trims and retimes stretch tween tracks to the new ends (`Clip::stretching`) while splits and carves crop them exactly. Any other key edit simply ends the tween form.
- `animation_presets/`: `AnimationPresets { in_preset, out_preset, loop_preset }` (in/out `AnimationPreset { kind: AnimationPresetKind, .. }`) → `AnimationPresets::transforms_at(at, length, letters) -> PresetTransforms { whole, letters }` of `PresetTransform` (offset, zoom, rotation, opacity, blur, wipe, reveal). Splits keep enter left and exit right; head trims advance `LoopPreset::phase`.
- `projection/`: `Project::shots_restyled(frame, Viewpoint, overrides)` / `shot` give `Shot { visual (animation_presets applied), projection, path, staging, letters, depth, cameras }`; `shots_restyled` takes previewed `Appearance`s (cameras included). `Projection` maps item-local (centred, unzoomed) points to output px stage by stage (`map`, `unmap`, `homography`, `affine`); `Homography::matrix()` is the `Place` row-major matrix. The nearest shown camera above projects in 3D, further ones re-project its picture as the z = 0 plane, the default camera (39.6°) keeps z = 0 at 1:1. `Viewpoint::Overview` drops a camera and everything above it; `Project::camera_view` is that camera's quad on its input plane. `front_shot` places a loose visual above every layer, and `Projection::{clipped, crosses_near_plane, stretch}` and `Wipe::shown` (delegating to `figure::LetterWipe::cut`) clip local polygons by camera near planes, the frame and wipes. `Visual::worn(Option<&Appearance>)` applies a previewed appearance; `Camera::{focal, dollied}` own the lens distance maths; `Format::center()` is the frame centre.
- `.rcut` (`file/`): per-clip `tracks` map named by `Field::name` (`volume`/`pan` for sound), `camera`, `animation_presets`, `transitions`, `markers`, placement extras in `transform`.
