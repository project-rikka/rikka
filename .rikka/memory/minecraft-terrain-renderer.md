- `render/terrain` replaces vanilla's per-frame terrain draw-list building; meshing, upload (`UberGpuBuffer`), the occlusion graph and `visibleSections` stay vanilla, and the vanilla multidraw terrain pipelines and shaders draw.
- `TerrainRenderer` is a singleton created in `LevelRenderer.invalidateCompiledGeometry` and released in `resetLevelRenderData`. `LevelRendererMixin` wraps `prepareChunkRenders*` (returns null), `renderGroup` and `renderOit`; nothing may use the vanilla `ChunkSectionsToRender`. Terrain-only mixins live in `mixin/terrain` (`rikka.terrain.mixins.json`); hooks inside shared root mixins (`LevelRendererMixin`, `LevelExtractorMixin`, `GameRendererMixin`) and the Vulkan accessors stay in `mixin/`.
- `SectionTable` mirrors every `RenderSection` slot (`index`): a 16-byte instance (origin, fade visibility, bound as vertex binding 1 with `firstInstance` = slot) and a 28-word record (per layer: base vertex, first index, 7 cumulative bucket ends; padded to 4 words). `cull.comp` gets every layout constant as a macro from `TerrainView.CULL_DEFINES`, so the Java constants are the only source. `RenderSectionMixin` marks slots on `<init>`, `reset`, `setSectionMesh`, `indexBufferUploadCallback`; `flush` rereads marked slots under the dispatcher lock and uploads only those. Fading slots are rewritten each frame until visibility reaches 1.
- `TerrainView` (one per camera: main view, Rearview's own) rebuilds its item list only when the visible-section version or `geometryVersion` changes: opaque layers grouped per vertex buffer in visible order, translucent as ordered runs in reverse order. Each frame `cull.comp` tests the section box (2-block margin) against the clip-space side planes of the real render projection (bobbed, from `GameRendererMixin`) and writes 3 fixed indirect draws per item; draws use `vkCmdDrawIndexedIndirect` inside Mojang's pass through `VulkanRenderPassAccessor`.
- `QuadBuckets` (from `SectionCompilerMixin`, opaque layers only) stably sorts quads into +X +Y +Z unassigned −X −Y −Z; only exactly axis-planar quads with plane in [-1, 17] and consistent winding get an axis bucket. The shader skips buckets facing away and merges neighbours (at most 3 runs). Bucket order changes which fragment wins exact depth ties (leaf interiors), a few pixels that vanilla itself does not render deterministically.
- `render/vulkan`: `VulkanCommands` (raw command buffer outside/inside passes, staging copies, Mojang's global barrier), `DeviceBuffer` (VMA), `ComputePipeline` (shaderc at runtime, push descriptors), `SwapchainDepth` (two more swapchain images in IMMEDIATE/MAILBOX so CPU and GPU frames overlap; FIFO unchanged).
- `LevelExtractorMixin` caches each visible section's `SectionDirtyState` (invalidated by `DirtyStateEpoch` on tracker reposition) and reads the clock once per block-entity extraction.
- Hitch control: `CompileFeed` (same mixin) admits first-time compiles only while the dispatcher's queue is below a window that doubles when workers ran dry and halves when they lag, so region copies spread over frames; recompiles of existing meshes are never held. `SectionOcclusionGraphMixin` ends the render thread's partial graph update after 1 ms and re-queues the unvisited nodes for the next frame; the asynchronous full update is untouched. `SectionRenderDispatcherMixin` lowers worker priority (see the performance note).
- Measured on RTX 4060 at 1080p: of the 0.34 ms solid pass about 0.17 ms is the vertex stage (bandwidth bound), RGSS filtering about 0.11 ms, fog and fade under 0.01 ms; per-draw overhead is negligible. Rejected: two-phase Hi-Z occlusion culling (mid-frame compute and pass split cost more than it culled), draw compaction, variable rate shading (fragment work left after fast filtering is about 0.04 ms), fog in the vertex shader.
- Opt-in terrain features (leaf culling, fog culling, fast filtering, compact vertices) are described in the Boost note.
