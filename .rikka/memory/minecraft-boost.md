- `mods/boost`: `BoostMod` (id `boost`, default off) owns one toggle per `BoostFeature` constant (default from `enabledByDefault`; only `RENDER_SCALE` is off). Hot paths read `BoostFeature.X.isActive()` (mod enabled and toggle on); `onChange(Runnable)` fires on the toggling thread, also at profile load before the device or level exist. Lang keys are `rikka.mod.boost.setting.<id>`.
- Unlike the always-on optimizations (performance note), a Boost feature may differ from vanilla by rounding or a small visual change. A feature costs nothing and changes nothing while inactive, takes effect at once when toggled, and has no fallback path. Each new trade-off is its own constant, never a silent change to an always-on path.
- `GPU_ENTITIES`: `render/skin`, see the skin rendering note.
- `DISTANT_ENTITIES` (`render/entity/DistantEntities`, `EntityExtractionMixin`): a living entity farther than 24 blocks that is neither passenger nor vehicle keeps its `EntityRenderState` for about 20 to 30 ms (phase by entity id) instead of extracting every frame; submit still runs each frame, so camera motion never lags.
- `ENTITY_CULLING` (`render/culling`, `rikka.culling.mixins.json`): entities and block entities fully behind opaque cubes are not extracted. `CullingSession` runs the `Rikka Entity Culling` thread, which alone owns an `OcclusionGrid` of opaque-cube bits fed by ordered messages from chunk load, unload and block changes; the render thread copies candidate boxes per frame (`CullBatch`) and reads one volatile result per object (`CullTicket` on `Entity`/`BlockEntity`). Rays run from points 0.5 blocks apart on camera-facing box faces; hiding needs 200 ms hidden, revealing takes one pass. Never culled: avatars, the camera's and player's vehicle tree, glowing or leashed entities, anything whose name tag would show, see-through text displays, the combat target, renderers that override reach (`RendererTraits`), boxes over 16 blocks. Only `LevelExtractor.extract` is culled, so Rearview's own extraction is not.
- Terrain features live in `render/terrain`. `LEAF_CULLING` (`LeafCulling`, `ModelBlockRendererMixin.shouldRenderFace`): a face between two leaf blocks is dropped only when the block behind the neighbour is a leaf or solid, so the outer two layers of a canopy remain; block changes dirty sections within 2 blocks (`LevelExtractorLeafMixin`). `FOG_CULLING`: `cull.comp` skips sections wholly at or beyond the render-distance fog end (cylindrical distance), off while fog is disabled. `FAST_FILTERING`: `rikka:core/terrain.fsh` replaces the RGSS filter by one trilinear fetch at the same mip. `COMPACT_VERTICES` (`CompactVertices`): meshes are rewritten to 16-byte vertices at compile and drawn by `rikka:core/compact_terrain.vsh`; a `TerrainView` draws only meshes of the current format, and `UberGpuBufferMixin` aligns allocations for both strides.
- `TerrainPipelines.of(vanilla, compact, fastFiltering)` derives terrain pipeline variants (classic, OIT, wireframe) from the vanilla one. Leaf culling and compact vertices rebuild all sections when toggled; the other two switch per frame.
- `RENDER_SCALE` (`mods/boost/scale`, `rikka.scale.mixins.json`, settings `render_scale_value` and `render_scale_sharpness`): two injections in `GameRenderer.render` bracket the world phase (before `renderLevel`, after `applyPostEffects`). The first swaps the attachments of the main, hand-depth and entity-outline targets with scaled copies (`ScaledTargets`, `Attachments.exchange`); the second swaps back and upscales into the native main target (`Upscaler`: edge-adaptive 12-tap upsample, then contrast-limited sharpening), so GUI, HUD glass, menu blur and screenshots stay native. Motion Blur, Color Saturation and Rearview run inside the scaled window. `TerrainSampler` gives terrain a negative mip bias while scaled. On RTX 4060 at 1080p it does not pay (upscaler about 0.16 ms, the world saves less); it is for fill-bound GPUs.
- Measure with the benchmark's `RIKKA_BENCH_BOOST` (benchmark note). On RTX 4060 / i5-12400 at 1080p fancy, defaults on against Boost off: `orbit_warm` 1500 to 2050 fps, `crowd` 650 to 1250, `gear` 180 to 500, `vault` 640 to 2090.
