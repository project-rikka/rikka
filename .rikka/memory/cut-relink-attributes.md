- Relinking model (`cut-project` `relink.rs`): `Edit::Relink(Vec<Relink { media, to }>)` swaps a `MediaId`'s `Media` for every clip using it in one undo step; `Project::relink_fit` returns `Error::UnknownMedia` or `Error::Mismatch` (`Mismatch`: different picture presence, lost sound, or shorter than the used source range). `Media::resembles` (same size, sound, duration within 100 ms) gates automatic matches only.
- `relocation.rs` is pure path logic plus one IO scan: `Relocation::between(old, found)` strips the shared folder tail and `candidates(other)` gives the rebased path, then the found file's folder; `Catalog::scan(root, wanted)` records only the wanted file names, case-folded (no hidden folders, no symlinked folders, depth 32, counts `unreadable`), and `find` ranks by shared parent folders, then exact case.
- `.rcut` stores `relative` (from the project folder) beside each absolute media `path`; `file/paths.rs` `located` keeps the absolute path when it exists, else the canonical relative one.
- App (`src/relink/`, `cut/relinking.rs`): `Cut.offline` is the set of used media whose file is missing, rechecked off-thread from `changed()` whenever the used media paths change (`Linked` snapshot, stale results dropped) and whenever a `rikka_xdg::Watch::paths` watch over the missing paths fires; opening a project with missing media opens the Link Media sheet. The sheet locates one file (probe + fit, then rebases the rest through `Relocation`), searches a folder (`Catalog`), and links all found entries as one `Edit::Relink`. `Command::ReplaceMedia` swaps an online clip's media through a chooser (offline media opens the sheet instead).
- Readers follow paths: `cut-render` `Supply` reuses a footage stream only for the same path; when media comes back, `Playback::reopen_offline` bumps `Preview`'s media round (`Request::media_round`), which makes `Supply` drop its failed streams, and clears the voices' vanished-file refusals.
- Attribute pasting (`cut-project` `attributes.rs`): `Piece::attributes()` lists what a copied clip offers (`Attribute::{Placement, Picture, Speed, AnimationPresets, Effect(slot), Sound, Camera}`), `Project::pastable(piece, clips)` keeps those some editable target `accepts`; `Edit::PasteAttributes { from: Box<Piece>, onto, attributes, keys: KeyFit }` appends effect slots and replaces the other groups, fitting keys by `KeyFit::{Maintain, Stretch}` (last key pinned) while tweens always span the target; speed is applied first so keys fit the retimed length. `Edit::RemoveEffects` clears stacks.
- App: the clipboard must hold exactly one piece (`Clipboard::single`); `Command::PasteAttributes` (Ctrl+Alt+V) opens the `src/attributes/` sheet (effects pre-checked), `PasteEffects` pastes every effect with kept timing, `RemoveEffects` clears selected stacks; all sit in the Edit menu and the timeline context menu.
