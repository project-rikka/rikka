- Model (`cut-project/src/transitions/`): a `Transition { kind: TransitionKind, before, after, easing, direction, tuning: Tuning, sound }` sits on a clip's `Ends { into, out }`. A joint A|B is stored on B's `into`; `out` only exists while nothing visual abuts the tail. `Project::normalize_transitions` (run after every `apply` and on load) moves a tail onto a newly abutting clip's head and clears non-visual clips; splits and carves clear the new cut's ends.
- `EditPoint { clip, edge }` names an edit point; `Project::canonical_edit_point` canonicalises a tail with an abutting visual neighbour (`Project::joins`) to that neighbour's head, and `Project::transition(edit_point)` reads what sits there. `Edit::Transitions { edit_points, transition: Option<_> }` sets or removes one transition on many seams (refuses locked/non-visual, `Error::NoEditPoint` when empty); `edit_points_among(&selected)` gives the joints between selected clips.
- `Project::transition_spans(layer)` resolves effective spans (each clip's head+tail parts share its length), `transition_span(edit_point)`, `transition_span_at(layer, frame)`, `frozen_frames` (footage frames frozen beyond media, closed form). `TransitionAlignment::{End, Centre, Start}` are presets of `before/after`; `with_length`, `aligned`, `with_kind` keep the rest. 29 kinds (`TransitionKind::index`/`from_index` order = `ALL`) in `TransitionFamily::{Dissolve, Wipe, Motion, Camera, Stylize}`; per-kind `knobs()` (`TransitionKnob`, ranged by `TransitionKnob::scale(kind)` as a `rikka_effects::Scale`), `directions()`, family default length (0.7 s; Camera/Stylize 0.35 s) and easing. Families are not stored in `.rcut`.
- `Project::scene_restyled` gives per-layer `SceneItem::{Clip, TransitionSpan { shots: TransitionShots { transition_span, out, into } }}`; `voices_at(frame)` gives `AudibleClip { clip, gain }` with equal-power crossfades (one voice when both sides continue the same media).
- `.rcut` stores `transitions: { into, out }` per clip with only the kind's knobs; cameras may not carry them.
- Rendering (`cut-render/src/transit/`): each side renders alone onto a clear canvas (regions: filtered canvas under their mask), `Mix` (eased progress, per-frame deltas for shutter blur, seed, scale, `fills` = side covers the frame → mirrored edges) composes them via one module per family (cut-render `transit/{dissolve,wipe,motion,camera,stylize}.rs`), and the result is placed as one `plan::Entry::TransitionSpan`. Camera and Stylize kinds cut at the eased midpoint; `swell()` (linear sine) drives shake/glitch/leak/burn/pixelate/liquid, `peak()` (eased) the rest. `Swatch` renders a transition between two arbitrary pictures (gallery thumbnails).
- App: `Cut { edit_point, side: Side::{Properties, Transitions}, transition_preview }` (`cut/transitioning.rs`); selecting an edit point clears the clip selection and opens the gallery (or properties if it has a transition). Hovering a gallery tile with an edit point selected previews the transition: the edit is shown through `LivePreview::rework` and the transport loops the span (no audio); clicking applies to `transition_targets()` (selected seam or joints among selected clips).
- `gallery/`: `TransitionPreviews` starts a `rikka_worker::Worker` `rikka-cut-gallery` once shared compute is published (`SharedGpu::on_compute`, stored through a weak slot and stopped and joined with the gallery), drawing sample cards (`cards.rs`) through `Swatch` into per-kind poster/strip `Computed`s, keeping the hovered kind's loop frames; `Tile` drags offer `gallery::MIME` (one byte: the kind index), which `Lanes` lands on the nearest edge (left of a joint = end at cut, centre, right = start at cut).
- Timeline (`timeline/lanes/transition_spans.rs`): bars in the bottom band of each row (hatched where frames are held), edge grips drag `before/after` (`grab::TransitionResize`), the band near a cut picks the edit point; right-click and Insert menus carry `transition_menu`. Panel settings live in `panel/transition.rs`; the easing picker target is `Target::Transition(edge)`.
