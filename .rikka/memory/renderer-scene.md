- 2D: retained `Scene` nodes (SDF shapes, text, icons, images, clips, backdrops, lenses). Image nodes may have corner `radii` and a `rotation` (`Node::rotation`/`NodeEdit::rotation`, radians clockwise about the centre; the quad grows 1 px for edge coverage and paint bounds cover the rotated box); flips come from `ImageSource::transform`. rikka-ui exposes them as `Sprite` (`radius`, `turned`, `mirrored`) drawn with `PaintCtx::draw_sprite`. Edit with `scene.edit(id).rect(r).fill(c)`, which damages on drop. Stale ids are no-ops.
- Gradients and shadows: `Node::fill_gradient`/`stroke_gradient` (and `NodeEdit` twins taking `Option`) paint a shape's fill or rim, an image's tint, a text's glyphs and decorations, or an icon with a `rikka_types::Gradient` (CSS linear gradient: angle clockwise from up, ≤ 8 stops, premultiplied sRGB, line resolved against the node's rect at emission). `Node::shadow(shape, sigma)` is a blurred rounded-box shadow (closed-form erf, rect inflated by 3σ, never stroked); pair it with `cut_out(shape)` for CSS box-shadow. Gradients live in the `ExtraPool` paint table (binding 8, beside the clip table) indexed by the instance's `paint_index`; the vertex shader turns emission-space position (`pos - shift`) into gradient `t`, so moved and relocated nodes keep their gradient. rikka-ui takes either a colour or a gradient as `Ink` (`Quad::fill`/`stroke`, `Sprite::tinted`, text and icons) and draws shadows with `PaintCtx::draw_shadow(shape, Shadow)`.
- Every rounded rectangle (fills, clips, cut-outs, glass panes, compositor corners) goes through `sd_rounded_rect` in `shaders/lib/canvas/sdf.slang`, which draws continuous-curvature corners: a superellipse reaching `RoundedRect::CORNER_REACH` (1.6, mirrored by the shader's `CORNER_REACH`) times the radius whose diagonal matches the circular arc, falling back to a true arc when the side is too short (pills, circles). CPU code that covers a corner (the compositor's display-corner masks) must cover that whole reach.
- Order key is `(z, stack, order label, insertion)`. `Node::stack(u64)`/`edit.stack(..)` name a stacking plane, `Node::order(u64)`/`edit.order(..)` give sparse labels. z/stack/label/layer edits neither damage nor re-emit; settling the order damages only nodes whose relative place changed. Without layers, settling merges only new or re-ranked nodes into the previous order; layers or a lost order sort whole.
- `visible(false)` is the hidden flag: the node keeps its instances, arena slot and chunk. Showing or hiding flips one bit of the per-node shown table (`draw/shown.rs`, binding 2) that the vertex shader reads, so it re-emits and re-lays out nothing. The shown bit and the per-node move offset are indexed by node index, which a later node reuses, so a removed node's instances are zeroed (and its offset reset) before its span is released: its chunk can keep covering that span without a re-layout. `rikka-widgets/tests/rendering/incremental.rs` replays changes through a mirror and compares every step with a fresh draw.
- `Node::clip_in(group)` / `edit.clip_in(Option<GroupId>)` give clip and cut-out in that group's space (normally an ancestor of the node's group; `None` is target space), so moving that group moves the clip without re-emitting. Text bands follow it.
- Same-id texture changes go through `notify_texture_updated` (whole nodes) or `Scene::damage_rect` (just the changed area). `edit.repaint_image(texture, changed)` swaps an image node's texture (rotating buffers) damaging only `changed`; `edit.image` damages the whole node. Image nodes re-emit only when their texture's `TextureBook` listing (slot, extent) changes; the book's revision lets an unchanged frame skip the check.
- Shape-local edits damage only what changed: with the rect unchanged, `edit.radii` (unturned) and `edit.clip` damage `RoundedRect::changed_corners`, `edit.stroke` damages `RoundedRect::rim`, and a group clip that changes only its rounding damages the changed corners.
- Groups (`create_group`/`set_group`) move scrolled content by an offset table without rewriting nodes. Offsets resolve on the CPU into one flat table, so nesting depth costs nothing per instance; only moved subtrees resolve and only changed entries upload. A move damages the subtree's member bounds before and after when it holds at most 64 members, else the group's shown rect, which `set_group` takes in the parent group's space and damage cuts by the group's resolved clip (also on removal and clip changes). `set_group` drops a parent that lies within the group itself.
- `set_group_clip(id, GroupClip)` bounds everything a group and its inner groups hold: `Inherit` (default), `Narrow(shape)` (in the parent group's space, intersected with the parent's clip), `Only(shape)` (drops the parent's clip). Resolved clips live in a second table (binding 3) that uploads only when a clip changes; the vertex shader folds a node's own clip and its group's into one clip with `RoundedRect::intersect` semantics (own corners kept only where they survive), so shared edges are covered once and pixels match an unsplit clip, so moving a group moves its inner groups' clips without touching nodes. `Node::clipped_by_group(false)` escapes it (raised overlays). Bounds, damage and text bands include it.
- Layers (`create_layer`/`set_layer`) give exact group opacity via `Blend::Mix` and form a stacking context only within one `(z, stack)` plane: a layer is ranked once per plane its members use (`order_layered`), so members of a higher plane draw at their plane's place in a separate fade pass with the same opacity and are never trapped under later lower-plane nodes. Chains resolve at `set_layer`; an opacity change patches fade segments. A fade captures the destination under the layer with one pass and mixes it back.
- A scene edited on one thread and drawn on another hands edits over with `scene.take_frame(&mut frame)` → `mirror.apply(&mut frame)`; both fill and drain a reusable `SceneFrame` (pass a spent one back to keep buffers). `apply` swaps nodes into the mirror and returns the replaced ones in the frame, so they (and their `Arc` counts) drop on the editing thread at the next `take_frame`. The mirror keeps its own id and batch. `take_whole_frame(&mut frame)` resends everything. Rare node fields (cut-out, lens, joined glass, backdrop cache) are boxed to keep `Node` small for this hand-over. `take_frame`, `apply` and the batcher's route and emit loops prefetch the slab entries (and retained slots, text layouts) a few nodes ahead; `Scene::prefetch(id)` exposes the same for callers walking nodes in order.
- `Scene::painted_over(node, area)` returns the bounds of every shown node ordered above `node` (layered nodes always count) that paints within `area`; the compositor uses it to decide what may go onto a display plane.
