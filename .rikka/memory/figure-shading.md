- Figures shade with node graphs, not a fixed template: PMX materials use `mmd`, VRM MToon materials `mtoon`, both prebuilt; `anime` is opt-in through `GpuModel::apply_style`. PBR imports stay on `rikka/standard` (and `skin`, `hair`, `eye`).
- Shared core (`classic/character.rs`, custom `Lighting` in one light loop): per light E = radiance × attenuation × `light.shadow.filter` (raw colour of translucent casters) × `npr.light_scale` (1/π in looked frames, 1 otherwise); the cel is `npr.toon_step` mode mtoon on N·L + shift, times the shadow map (`light.shadow.map`, no screen shadow); colour = lerp(shade, lit, cel). Ambient = sky irradiance (mmd) or `light.environment.equalized` (mtoon/anime, `gi_equalization`) × lit. Emission is an `Emission` closure so emission bloom sees it.
- `mmd`: material colour = saturate(`base_color` + `ambient_color`) × texture × vertex colour; when `toon_texture` is set (`texture.bound`) the colour is (lit + sphere add) × lerp(ramp(−1), ramp(N·L), shadow), else the shade-colour step with the sphere add on the lit share; `npr.matcap_uv` view-normal flipped as in PMX; specular = E × `specular_color` × 154/255 × max(N·H)^power × shadow; edges are unlit `outline_color` at screen width (`rikka_npr_outline_width` converts pixels with depth 1 in orthographic views, so ortho edges keep their pixel width).
- `mtoon` (MToon 1.0): uv animation via `vector.uv_transform` with the mask's blue channel, shade texture, shading shift (+texture × scale only when bound), toony, GI equalization, rim = (matcap × factor when bound + parametric fresnel) × rim texture, split into a lit share (`rim_lighting_mix`) and a flat one; outline colour × lerp(1, lit result, `outline_lighting_mix`) in its own Lighting; width × width texture green, world or screen.
- `anime` = both cores plus figure touches that start at 0 and are raised by class presets: `hair_shadow` (+`hair_shadow_distance/reach`, scales the light's shadow by `npr.hair_shadow`), `face_shadow` (mixes N·L towards `npr.face_procedural`), `scatter` (`npr.scatter_bands`), `strands` (`npr.kajiya_kay`), `depth_rim` (`npr.depth_rim` × light side). Their Lerp/Multiply gates on these parameters are feature-specialized, so features at 0 cost nothing.
- Wetness: `npr.wet` darkens lit and shade albedo and gives the film; per light `npr.wet_glint`, ambient `npr.wet_film`; everything else × (1 − film_view).
- Classes (`ToonSurface` in rikka-model-core, classified by keywords then texture stem) stay data: rikka-model-gpu applies the class preset when the template declares it (porosity on mmd/mtoon, features on anime), sets character layers (hair → `HAIR_LAYER`, face/mouth/blush → `FACE_LAYER`, eye/lash → `SEE_THROUGH_LAYER`), `see_through.amount` 0.35 / reach 0.08 on eye/lash, and draws Hair with alpha Blend as alpha-tested (cutoff 0.5).
- See-through: the generic pass re-shades see-through draws; `rikka_coverage` keeps the material alpha in that pass even for opaque draws, so `npr.skin_reject` (YCbCr pale-skin test, 1 outside the pass) in the alpha hides eyelid skin painted into eye textures.
- Character passes (looked frames, `Look::characters` masks): `rikka.three.hair_depth` / `face_depth` depth layers feed `npr.hair_shadow`, `npr.see_through`, `npr.depth_rim` and `npr.scene_depth`.
- `Head.forward`/`up` must be the face frame: callers take it from rikka-model-gpu `HeadRest::place(&instance)` (head rotation since rest applied to `Anatomy::forward()`, centre +8 cm, radius 10 cm, × rest hips height).
- Render-bench, RTX 4060, shade pass p50 (`three: miku`, `three: miku styled <preset>` restyle the PMX with prebuilt presets): `mmd` 429 µs, `mtoon` 424, `anime` 471, `genshin_body` 525, `hybrid` 730, `pbr_skin` 294.
