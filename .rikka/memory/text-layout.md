- Top of the `crates/text` engine: rikka-text-unicode, rikka-text-font, rikka-text-shape and rikka-text-catalog feed it (it does not depend on rikka-text-raster); `rikka-text` and `rikka-svg` (SVG text) are its consumers.
- `Paragraph::new(text, &TextStyle).spans(&[StyleSpan]).tab_width(n).shape()` gives a `ShapedParagraph` (an `Arc` handle). Text excludes the line terminator; spans are byte ranges with family, weight, style, absolute px size, underline, strikethrough. Colour never enters shaping. `TextStyle::caps(Caps)` (CSS `font-variant-caps`: small, all-small, petite, all-petite, unicase, titling) turns on the matching OpenType features for the whole paragraph; `Shaped` keeps it so edge reshaping at breaks uses it too, and plans and script equivalence are cached per caps.
- Shaping pipeline: bidi (auto base) → UAX #24 script runs → style spans → per-grapheme face choice (ASCII runs take a bulk path through the primary face's ASCII coverage mask) → one rikka-text-shape call per (face, level) unit, split into runs by style. Adjacent runs of different scripts join a unit only when their plans are equivalent for that face (`ShapePlan::is_equivalent`, the verdict cached on `FaceInstance`; plans themselves come from the `ShapeFace` cache); Hiragana and Katakana join Han in Noto CJK.
- Face choice per grapheme: a Common character keeps the previous fallback face, then the primary face, then the previous fallback face if it covers the cluster, then `catalog().fallback`.
- Faces are `FaceInstance`s cached per `FaceMatch` (bounded: the match map is cleared at 4096 entries, instances nobody holds are dropped past 256): font, `ShapeFace`, em metrics, `Synthesis` (rikka-text-font, re-exported). Synthetic bold widens advances by `Synthesis::extra_advance_em()`. Variations come from `FaceMatch::variations` with `opsz` dropped, so shaping and raster use the face's default optical size.
- Fallback faces load synchronously when a paragraph first needs them; fallback search is in-memory and takes microseconds.
- `ShapedParagraph::outline_glyphs()` lists the (face, location, synthesis, glyph) of every non-colour glyph, which rikka-text uses to warm curves.
- `LocationId` interns variation locations globally; `LocationId::location()` returns the `&'static Location` for raster keys.
- Shaped glyphs are SoA columns in em units in logical order (RTL runs reversed), with cluster start/end and flags (unsafe-to-break, whitespace, tab, separator, word separator). Break segments with em/px widths are precomputed, so re-laying at a new width or size never touches glyphs until rows are emitted.
- `LayoutParams::letter_spacing` (px, clamped to ≥ −0.5 em) adds CSS-style spacing after every non-empty, non-line-break shaping cluster (marks and ligatures share one; the ellipsis gets none). It is counted in segment `Measure`s, `for_each_cluster`, piece measuring and emission, so widths, wrapping, alignment, carets, hits and selections agree; emitted advances include it (RTL glyphs shift right by it inside their advance).
- `shaped.layout(&LayoutParams)` or `layout_into(&params, &mut ParagraphLayout)` (allocation-free when the layout is reused). Rows: fixed `line_height`; the baseline comes only from each run style's primary face (`RunStyle::primary`), never from fallback faces, so CJK or emoji fallback never moves a row. Each face's strut (`EmMetrics` ascent/descent) is its line box re-centred on half its cap height when the font maps `H`, else on its ascent/descent box, so capitals and kana sit at the row middle.
- Breaks at unsafe-to-break glyphs reshape only the edge segments around the break. Trailing whitespace hangs; tabs advance to multiples of tab width × the face's space advance; rows reorder with L1 + L2.
- Glyph px output: `x` includes the x offset, `y` is a y-down offset from the row baseline. Decorations carry a y-down top edge from the baseline.
- Editing: `hit`, `caret`, `row_of`, `row_start`/`row_end`, `selection_rects(range, &mut Vec)`, `visual_step` on `ParagraphLayout`; `Cursor { index, affinity }` where `Before` sticks to the preceding grapheme. `SelectionRect` names its row. Grapheme and word boundaries (`next_word_boundary`, `previous_word_boundary`, `word_range_at`, grapheme steps) read any `TextSource` (`byte_len`, `covering(range)` → start and `Cow<str>`, implemented for `str`) through a window around the index that starts and ends where a grapheme cluster and a dictionary run must restart, doubling while an answer touches its edge, so editor steps never segment a whole line. Every word helper takes a `WordRule` (`Prose` or `Code`, re-exported from rikka-text-unicode); word steps are `WordSegments::new(text, rule)` (UAX #29 with the Thai, Lao, Khmer, Myanmar and Chinese/Japanese dictionaries) grouped into runs: adjacent space segments and adjacent symbol segments merge, word segments never join. Windows start and end outside runs that `needs_dictionary` until the radius reaches 4096 bytes; from there they may cut inside such a run, so a long unpunctuated Chinese, Japanese or South-East Asian run costs a bounded window per step. A window trusts only boundaries three segments away from an edge that is not the text's own. Next ends the run and the spaces after it, previous skips spaces back to a run start.
- `Wrap::WordOrGlyph` is the default everywhere (`LayoutParams::new`, rikka-text's `TextSpec`, rikka-ui's `TextRun`): word breaks, plus grapheme breaks only inside a word wider than the row. `Wrap::Word` overflows instead. `ShapedParagraph::min_content_width(&params)` is the widest segment (Word/WordOrGlyph), widest cluster (Glyph) or natural width (None), from the same widths the breaker tests, so laying at that width never glyph-breaks a word.
- Ellipsis (`ellipsize`, `Wrap::None`, width) cuts in logical order at a cluster, trims spaces, appends "…" (or "...") at the base level, shaped like CSS `text-overflow` in the primary face of the cut style (then the paragraph's base face, then the face at the cut), so every cut row ends in the same mark whatever script it cuts; `Row::is_elided`, `ParagraphLayout::shown`.
- Tests use the global catalog and the session fonts.
