- `Look::emitters: Vec<Emitter>` beside the ambient `Look::particles`. Every particle is a pure function of `(emitter, index, frame.time)`: no state, so scrubbing, re-rendering and offline export give identical pixels.
- Public model (`src/look/emitter/`): `Emitter { seed, shape: EmitterShape, track: EmitterTrack, emission: Emission, launch: Launch, forces: Forces, ground: Option<Ground>, appearance: Appearance, lighting: ParticleLighting, layers, bloom }`; `Curve`/`Gradient` hold 1–4 keys over normalized age (`keyed::<N>` checks N at compile time); `EmitterTrack::keyed` (≤ `MAX_TRACK_KEYS` 64 timed `Mat4`, decomposed to TRS, quaternions aligned, nlerped) or `fixed`; `Emitter::at` premultiplies the track.
- `Emitter::particle(index, time) -> Option<ParticleState>` and `capacity()` are the CPU twin of `shaders/lib/rikka/emitter.slang`; gizmos and tests use it. Any change to the closed form must land in both `evaluate.rs`/`noise.rs`/`track.rs`/`shape.rs`/`curve.rs` and the Slang module, same operation order and random draw order (`Draws`).
- Index layout: `Emission::slots()` = min(⌈rate·lifetime⌉+1, ⌈(end−start)·rate⌉+1, `max_particles`) ring slots, then burst particles (≤ `MAX_BURSTS` 16, keys `0x8000_0000 | burst << 24 | j`). A slot shows birth n = k·slots+i, the latest with `n + jitter(n) ≤ (t−start)·rate`; jitter is the first draw of the particle's PCG stream.
- Motion: linear drag with exact exponentials (`phi`/`psi` series below kt 0.1), wind as the drag target, ground contact by fixed 12-step monotone Newton (concave from the right, convex from the left, bracketed by the sign of y''), ≤ 8 bounces then rest; curl noise (three Perlin gradient fields) displacement = strength·age·curl(birth·frequency + seed offset + age·flow); attractor = exponential blend.
- GPU (`src/space/emitters/`): `EmitterFrame` (in `FrameScratch`) packs `GpuEmitter` (736 B) + `GpuEmitterKey` (48 B), validates, sorts far-to-near by track distance, uploads per frame slot (`FrameData::write_emitters`); `rikka.three.emitters.evaluate` (compute, one dispatch per emitter, 64-thread groups) writes 64-byte particles (position, previous position at `scene.previous_time`, velocity, rotation, half-packed lit and emitted radiance, flipbook frame, hash) into the per-slot `rikka.three.particles` buffer (`graph::Buffer::Particles`); lit particles take the directional lights with cascade shadows plus sky SH ambient and an HG translucency lobe.
- Drawing: one instanced draw (6 vertices) per emitter in the shade pass after the ambient particles, depth-tested without depth write, premultiplied blend for all modes (additive writes alpha 0), unsorted within an emitter. The emission target (present when a reachable composite node reads `RenderLayer::Emission`, e.g. a Glow `source` socket) gets `emitted·alpha` when `bloom`. Sub-pixel quads widen to 1 px and lose opacity.
- With temporal AA, `rikka.three.emitters.motion` accumulates coverage-weighted motion into an RGBA16F image the temporal resolve blends over surface motion (and lowers reactive and skips disocclusion by that coverage); with a layers image (a reachable composite node reads `RenderLayer::Layers`), `rikka.three.emitters.layers` writes the emitter's layers where coverage ≥ 0.5.
- Presets: `rain`, `snow`, `sparks`, `embers`, `petals`, `fireflies`, `dust`, `magic`, `confetti`, `leaves` (amount, area or radius or speed, wind); emissive ones state luminance in nits over `NITS_PER_RADIANCE_UNIT`. Ground heights are world y (default 0).
- Tests `tests/look/emitters.rs`; bench `three: look frame with 100k emitter particles at 1080p` (≈ 0.1 ms evaluate + 0.2 ms extra shade on an RTX 4060, zero steady allocations).
