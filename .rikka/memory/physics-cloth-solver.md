- Layout (`src/layout`): `Topology` orders particles per layer group by tree level and colours edges greedily smallest-last (`colouring.rs`, pinned particles never conflict) twice: one colouring of all edges (structural, shear, lateral) for the GS `stretch` pass and one of structural edges only for `retidy` (`Group { plan, structural_colours, stretch_colours }`, plan holds retidy ranges first). Bends, shapes and wraps are Jacobi slot families whose `applied` weight is the inverse mass times one share per constraint, so internal constraints conserve momentum. `bake` writes one statics buffer of sections from styles; `rest.w` carries the particle's `cover`; tethers get 0.1 % slack.
- Per step GPU (each kind recorded for all figures of a round before the next kind, so whole-buffer hazard tracking inserts one barrier per kind, not per figure): one frame write per figure (`FrameLayout` puts palettes, pieces, colliders, planes first; `planned` is their end), one `state`→`posed` copy per epoch, `skin_body` then `targets` for all boundaries, then per epoch one `obstacles` dispatch over every figure of the round's table (each thread finds its figure from the table counts), `probe`/`wraps` and the solve: each layer's pieces are packed (largest first, first fit; `topology.rs` `packs`) into groups of ≤ 768 particles, every group is one 256-thread workgroup (`THREADS` in `cloth/solve/state.slang`; every solve loop strides by it, so a thread owns up to 3 particles), and all groups of one kernel variant run in the same dispatch, so the slowest group sets the time. Then `normals` and `drape`. Jobs are `JobRecord`s (device addresses) in one buffer; `cloth/job.slang`'s `Job` mirrors it field for field under scalar layout (a mismatch hangs the GPU). `PieceRecord.contact.x` is 1 for sheets; `PieceRecord.layer_triangles` is the figure's triangle range of the piece's layer (own triangles before it are inner layers, inside it the same layer). `obstacles.slang` stores cloth items' sphere radii negated, so `probe.slang` `walk` reaches cloth with `cloth_reach` and the body with `body_reach`.
- `drape.slang` reads one 176-byte `BindRecord` per render vertex (header bit 31 = strand): triangle binds hold 3 influences, strand binds 16 strand node ids + weights (sorted, zero-terminated) into the statics `strand_nodes` section (`StrandNodeRecord`: GPU particle ids + rest tangent/bitangent); strand node frames are rebuilt inline each step, no extra pass.
- `Inertia::carried`/`carried_turn` range −1..1: negative values shift the cloth against the frame's motion (exaggerated inertia); centrifugal spin uses only the physical felt turn. `Style::settling` damps velocity relative to the piece frame (`PieceRecord.settling.x`), unlike `damping`, which damps world velocity and so makes cloth lag.
- Solve substep: predict (inertia shift, damping, settling, gravity × falloff, wind/noise only when gusting, centrifugal, flutter) → sync → stretch colours → Jacobi (bends with degenerate-area guard, 0.25×hinge cap and Kelvin-Voigt XPBD Rayleigh damping `BEND_RAYLEIGH = 0.006` skipping pinned vertices so rigid rotation has zero phantom torque; shapes with `sine > 0.02`, 0.25×edge cap and mass-independent `RESTORE_GAIN = 20.0`; wraps; self contacts, inner sheets excluded) → sync → settle (gathered slots, tethers, pull, max distance, backstop/floor with `BARRIER_SETTLE = 0.85`, DAT truncation and self-push with `SELF_SETTLE = 0.80`, inner-sheet `layer_contact`, body contact + C0 collider rescue) → sync → grip → sync → finish (velocities, attenuation, inward pressed velocity removed, same-layer and inner-layer partner velocity coupling, substep reversal shock damping `SHOCK_SPEED = (0.05, 0.35)` / `SHOCK_DAMP = 0.70`) → sync → retidy (`keep_limb_side` before edge passes on last substep, stretch cap, free-edge axial velocity damping `AXIAL_DAMP = 0.20`) → `post_project` (body mesh on last substep, colliders every substep) → last-substep strict-outward `retidy_edges` → firm grip → sync.
- Rest (`step/rest.rs`): while no posed figure moves and there is no wind, `Rest` judges 15-step windows of the lagged `Movement { speed, jitter, stirred }` (max displacement speed, max speed × wavering, share of particles ≥ 0.1 m/s; three stats words per figure): it sleeps (no solve, motion 0) once a window peaks below 0.03 m/s, or below 0.1 m/s without falling under 60 % of the lowest earlier peak. Each particle keeps an EMA `drift` (`DRIFT_MEMORY = 0.85`, checkpointed) of its step displacement; `steadied` in the solve epilogue damps low-amplitude oscillating velocity (`MICRO_DAMP = 0.55` when `pace < 10 mm` and `wavering > 0`, without freezing position during motion) and when still pulls positions back toward the epoch start by `steadying × wavering` or global `freeze`.
- Child-only restore or bearing-propagated angle limits fought the stretch constraints (energy pumping, exploding ribbon hair); both are two/three-particle constraints now, and `shape_slots` restore uses mass-independent `RESTORE_GAIN` (20.0) over `weights.x + weights.y` so fine meshes do not snap rigidly to the skinned pose. `bake` scales dihedral bending (`bend_compliance`: `10^(-3 + 5*(1-s))`) by Discrete-Shells aspect `(a1 + a2) / (3 * l^2)` and areal density ratio `(areas / m_avg) * DENSITY_REF` (and compression `10^(-9 + 8.5*(1-s))` by `(l^2 / m_avg) * DENSITY_REF`), making cloth bending and non-locking compression independent of mesh resolution and density.
- Velocity attenuation removes only constraint corrections measured against the coasting position (inertia without external acceleration); measuring against the full prediction leaves a phantom gravity velocity and the cloth never rests. The part of a body or cloth-contact push that only undoes this substep's attenuated corrections (along the push direction) is attenuated too; keeping it as velocity pumps energy wherever constraints press cloth into the body or an inner layer. Body pushes that clear penetration already present at the substep's start (same threshold, body at its previous pose: a snug radius change, a new candidate) shift `starts` instead of becoming velocity (`Held.settled`), so a particle pinched between a hand and the hip never kicks; penetration made by the body moving this substep still throws the cloth.
- Each substep ends with `retidy`, `post_project`, and (on the last substep) a strict-outward `retidy_edges` pass so `keep_limb_side` and `post_project` never leave edges torn or pull vertices back into the body. `keep_limb_side` runs in its own colour pass before edge clamping on the last substep, capping shifts at `0.85 * span` and `lift` at `0.5 * span`. `strands.rs` filters intra-clump `Lateral` links by `MIN_CROSS_LINK_LENGTH` to prevent degenerate sub-millimetre links.
- `Style::extent` adds min-distance tethers (`TetherRecord.shortest` = rest pin distance × extent) pushed in settle at `EXTENT_SHARE` per substep, never into the pressed contact normal, scaled by `max(activity, EXTENT_HELD)`; `activity` (`Rest::activity`, carried in `JobRecord.rest_terms.y`) is 1 while the posed figure moves and fades to 0 over 30 still steps. Without it the envelope skirt piles up in the lap crease when a thigh rises; at full strength it never rests (stick-slip).
- Body, collider and cloth contacts are in the physics-cloth-contacts note.
