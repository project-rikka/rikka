- Public crate `rikka_polymesh`; `Polymesh` holds `positions`, `edges`, `face_offsets` (faces + 1, starts at 0), `corner_verts`, `corner_edges`, generic `attributes`, `uv_maps`/`color_attributes` (`Layers`: attribute names + active + render), `vertex_groups` (sparse `Influence` lists, `weights` empty or one per point) and `shape_keys` (absolute positions per key, key 0 is the basis, `relative_to` by index).
- Invariants: faces have ≥ 3 corners, every corner edge joins its corner and the next one, attribute lengths match their domain, well-known names have fixed domain/type. `validate()` reports, `sanitize()` repairs (counts in files are never trusted), `ensure_edges()` fixes only inconsistent corner edges and appends missing edges. Loose points/edges and repeated vertices in a face are legal.
- Well-known data are ordinary attributes under the reference names (`material_index`, `sharp_face`, `sharp_edge`, `uv_seam`, `crease_*`, `bevel_weight_*`, `.select_*`, `.hide_*`, `custom_normal` as Corner Vec3 object space, `.pn.<uv>` pins, shared `.uv_select_vert/edge/face`) with typed `x()`/`x_mut()` (creates on demand)/per-element accessors; absent = default.
- Topology-changing code never names layers: `Polymesh::{resize, gather, copy, interpolate, push_copy, push_interpolated}(Domain, …)` move everything of a domain (Point also moves positions, weights and key positions; Edge the vertex pair; Corner `corner_verts`/`corner_edges`, structural data follows the strongest source). `rebuild_faces(&[(source face, source corners)])` rewrites faces; `merge_points(targets, MergeData::{Mix, KeepTarget})` is the reference's weld (collapse, self-split, duplicate faces; Mix averages groups like merge-by-distance, KeepTarget like Mirror/Array).
- Interpolation follows the reference CustomData: bools OR (weight > 0), ints round the weighted sum, others weighted sum; colours default to white. `Values::convert` follows the reference's implicit conversions; `adapt_domain` follows the reference's domain adaptation rules.
- Normals keep the reference's numbers: Newell face normals (degenerate → +Z), angle-weighted point normals with the fast acos, fan-based corner normals; `Shading::Vertex` is the pre-4.1 no-autosmooth look. `encode_custom_normals`/`decode_custom_normals` convert to/from the reference's short2 fan-space form (encoding may sharpen edges like the reference).
- `triangulate()` is the reference's looptri choice (quad flip test, ear clipper for n-gons); `triangulate_face_with(QuadMethod, NgonMethod)` is the Triangulate modifier/operator choice incl. beauty fill.
- `transform` flips winding on a negative determinant, `transform_without_flip` does not (Array, Mirror). `join`/`append` unite attributes (adapting domains), groups and keys by name and fill missing custom normals with computed ones.
- `to_mesh(&ToMesh)` builds a `rikka_model_core::Mesh` through `MeshAssembler` (weld per point + corner data), MikkTSpace tangents (the reference's variant; `w` negated because UV v is flipped), one submesh per material index, four normalized influences, morph targets with normal deltas, `polygons` filled. `from_mesh(&Mesh, &FromMesh)` rebuilds faces from `polygons` or welds triangles; it derives sharp edges/flat faces and stores custom normals only when they don't reproduce the given normals.
- `Codec` encodes the whole mesh; decode validates. Tests compare against numbers from the reference.
