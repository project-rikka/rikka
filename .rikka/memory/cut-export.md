- `cut-export` is UI-free over cut-project, cut-render, rikka-audio-decode, rikka-audio (`Pan`), rikka-video and rikka-image-edit. Facade: `Settings { target: Target::{Video, Audio, Still}, video, audio, still }`, `Video` (container, codec, encoder, speed, `Compression`, quality, bitrate, `Resolution`, `FrameRate`, sound, sound bitrate), `Preset::{High, Standard, Small}`, `Audio` (`SoundCodec::{Wav, Aac}`, `WavDepth`, sample rate, bitrate), `Still` (`StillFormat`, resolution), `Range`/`Span`, `Plan`, `Mixdown`, `Order`, `Job`, `Report`, `Phase`, `Summary`.
- Presets set only container, codec, constant quality, resolution, frame rate and sound; encoder, speed and bitrate stay. `Video::preset(format)` finds the preset a setting equals (else the UI shows Custom); `Small` lowers projects over 720 px short side to 720.
- `Resolution::Short(side)` scales the project's short side (capped at 4×, `offered(format)` lists only those), sizes rounded to even. `FrameRate::Project` or one of `FIXED`.
- `Span` is a half-open timeline range; `Range::suggested` picks In–Out when a mark is set (mark-out is inclusive). `Plan` maps output frames to timeline frames by nearest start time (ties earlier) with exact integer math, and gives each output frame its sample range, so sound and picture tile the same duration.
- `Mixdown::new(project, first, sample_rate).fill(stereo)` reproduces preview playback offline: per timeline frame it asks `Project::voices_at` at the block's start and end (gain ramp, equal-power transitions), keeps one strand per (layer, `Alignment` that `continues`), each a `rikka_audio_decode::Decoder` seeked to `clip.source_position` and a High `rikka_resample::Resampler::at_speed` (rational ratio source rate × speed : output rate), mixed through `rikka_audio::Pan` (the engine's pan law), then clamps. Monitor volume is not applied. Unreadable sound is recorded in `undecodable()`.
- `Job::start(order, imaging, report)` runs `rikka-cut-export` on a `rikka_worker::Worker` whose stop cancels the job's `CancelToken` (drop cancels and joins): video draws each frame with `cut_render::Sequence` (`Request::sized(..).rolling()`, waits for exact footage), downloads with `Picture::to_rgba8` (repeated pictures reuse their pixels) and hands frames (3 ahead) to `rikka-cut-encode`, which pushes the mix and frames into `VideoEncoder` (fast start; no sound track unless `Project::is_audible`). Audio-only writes `WavWriter` or AAC `AudioEncoder` (.m4a); still saves the playhead frame by extension. `Report::Previewed(ComputedFrame)` arrives about every 400 ms; `job::Progress` throttles `Advanced` to 100 ms. Failures travel typed: `Report::Failed(Error)` becomes `Phase::Failed(Arc<Error>)` (`Phase` is `Clone`, compared with `matches!`).
- Every job writes a hidden `.<stem>.<pid>-<nanos>.part.<ext>` beside the target (`output.rs`); cancel or failure removes it. Only an `Order::overwriting()` order renames over the target; otherwise it hard-links into the first free "name (n).ext", so no existing file is replaced, and `Summary.path` is where it landed. A job that reached Finishing completes even when dropped.
- Tests (`tests/`): plan mapping table, mixdown placement/speed/pan law, and headless end-to-end video, WAV, still and cancel jobs.
- App side (`apps/general/cut/src/export/`, `cut/exporting.rs`, `preferences/`): File → 書き出し… (Ctrl+M) and フレームを書き出し… (Ctrl+Shift+E, Still). The sheet shows target segments, preset/format segments, a facts line, the destination (auto-unique name in the last export folder, else project folder, Videos, home; 変更… opens the save chooser, and only a selected path equal to the final name is sent overwriting), warnings, and a folded 詳細設定 with every option. Both sheets are modal over `sheet::present` (`is_modal` pauses shortcuts and commands; the unsaved sheet draws above them); closing the window drops the draft sheet but a running job only ends with the window. The progress sheet shows the `Computed` preview, pace, remaining time, backend, and on finish opens `Summary.path` or its folder.
- `Preferences` owns domain `rikka.cut`; `preferences/export.rs` stores the last `Settings` (stable value names) and the export folder when an export starts.
