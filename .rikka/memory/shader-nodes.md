- `Library::standard()` (`src/nodes/mod.rs`) gathers one file per family: `closures.rs` (`bsdf.*`), `light.rs` (`light.*`, `npr.cast_gate`, `npr.head_light`), `shade.rs` (diffuse shaping, ramps, IDs, emission, lines), `face.rs` (head, face SDF/procedural, nose, eyes, hair shadow), `specular.rs` (stepped, GGX, matcaps, strands, stockings), `rim.rs` (rims, screen, depth, view transform), `outline.rs` (hull width/direction/depth/fade, perspective flatten), `color.rs` (`color.*`, `vector.bump`, `vector.from_tangent`/`to_tangent`, `vector.curvature`), `texture.rs` (`texture.bound`: 1 when a texture is bound; unbound textures sample white, so graphs fall back to their own neutral values with it). Family prefixes are checked by `rikka-shader-graph/tests/library.rs`.
- Function nodes are `Function::new(id, title, doc).value(inputs, output, code)` or `.packed(inputs, code, struct, [(port, ".member")])`; every `{port}` in `code` must be an input and every input used (guarded by `tests/library.rs`).
- Slang homes: NPR maths in `shaders/lib/rikka/npr/{head,light,shade,face,specular,rim,screen,outline,wet}.slang` re-exported by `rikka.npr` (`rikka_npr_*`, packed structs `RikkaNpr*`); closure models in `lib/rikka/closures/*.slang` re-exported by `rikka.closure` with their `rikka_closure_*_data()` defaults; composite-capable helpers and new ops in `rikka.graph` (`rikka_graph_*`). 
- Sites come from tokens and port defaults: a port defaulting to `Input::LightDirection`/`Shadow` makes the node per-light unless linked or set (`Flat::taint` reads context defaults); `$light`/`$shadow` per light, `$indirect` ambient, `$pixel` restricts to pixel sites (used for implicit-derivative texture reads and `ddx`), `$context` any material site. Hull-only nodes default to `Input::SmoothedNormal`. Hull vertices carry `tangent` (`RikkaHullVertex.tangent`).
- Conventions: directions are world-space unit vectors towards light/camera; facing values are N·L in -1…1; `HL(x) = x/2 + 0.5`; head `right = up × forward` (screen right on a face looking at the camera); figure `scale` = head radius / 0.1 m (no real model scale exists); options sockets are floats switched at run time (`int(mode)`), so set options stay live uniforms; textures read at mip 0 with `sampled_level` unless the node is pixel-only.
- Per-light texture reads must happen before the light loop: split a node into a surface sampler and a per-light consumer (`npr.face_sample` → `npr.face_sdf`).
- Utility nodes for presets: `npr.light_scale` (1/π looked), `npr.skin_reject` (see-through alpha), `vector.uv_transform` (MToon uv animation + KHR transform), `npr.wet`/`npr.wet_glint`/`npr.wet_film`; `light.shadow.filter` is the raw translucent-caster colour; `npr.outline_width` mode `screen` = width × depth / focal.
- Closures are `IShadingModel`s read through `resolve`: diffuse (EON), glossy (aniso GGX, DFG energy, LTC areas), sheen (Zeltner LTC), translucent (back Lambert), toon (normalized, edge widened by the light's angular radius), skin (`RikkaOpenPbrModel` with `rikka_closure_skin_data()`); all use `shadow.transmittance()` and the `RikkaIndirect` bent-normal/specular-occlusion helpers. None model wetness.
- Ops that may drive worlds or filters (map range, compare, switch, noise, textures, colour adjustments, mapping) are `Op`s with identical CPU (`Op::compute`) and Slang maths; `rikka-shader-compile/tests/ops.rs` renders them against the CPU.
- Adding a node: write the Slang in the family module, add the spec in the family file, then `rikka-shader-compile/tests/catalog.rs` compiles it automatically in every site it validates in (surface, light, ambient, combine, displacement, outline, composite); add a rendered check in `tests/npr.rs` or `tests/closures.rs` when its maths matters. Heavy closures build in ~10–20 s per template.
- Gates: a single-output function node declares `Function::new(..).gated("strength", Bypass::Input("value"))` or `Bypass::Constant(Constant::scalar(0.0))` (`FunctionCode::gated` for extension libraries) when input X = 0 makes the result exactly input Y or a constant for finite inputs; the generator then skips the node and its exclusive inputs at run time. Declared on `npr.brush`, `npr.expression`, `npr.face_highlight`, `npr.mask_band`, `npr.rim_shadow`, `npr.skin_reject`, `color.saturated_shade`; `tests/library.rs` checks the ports and types. Packed nodes cannot declare gates (their consumers' Lerp/Multiply gates cover them, as in `anime`).
