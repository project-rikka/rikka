- Sound (cut-project `footage.rs`): `Mix { volume, pan, muted, fade_in, fade_out }` with `Fade { length (frames from the edge), shape: FadeShape }`; volume/pan are `Property::Mix` tracks. `Clip::level_at(at, shown) -> Level { gain, pan }` folds keys, mute and fades and is what preview `playback/` and export `Mixdown` hear (`AudibleClip.gain` stays the transition crossfade); `audible_mix` gives the keyed mix at a fractional frame. Crops fit fades into the clip (`Mix::fitted`).
- Timeline sound band (`timeline/lanes/sound.rs` paints, `parts.rs` geometry, `leveling.rs` gestures): the volume rubber band uses a sqrt-of-gain scale (`level_y`/`volume_at`), drag moves the base or the two surrounding keys, Ctrl+click adds/removes a key, keys drag in time and value, top-corner handles drag fade lengths; the waveform follows the envelope (`wave::AudioLevel`).
- Markers (cut-project `markers/`): `Marker { at, length, name, note, color: MarkerColor }` in `Markers` with `MarkerId`s from the project counter. Timeline markers live on `Project` (timeline frames, rippled by `ripple_from`), clip markers on `Clip` in source frames (follow moves/slips, both split halves keep them; `Clip::marker_span` gives the visible timeline span). `Edit::Marker { on: MarkerScope::{Timeline, Clip}, change: MarkerChange::{Add, Set, Remove, Clear} }`; `Applied.marker` names an added one. Snap points include markers.
- Marker UI: `timeline/ruler.rs` draws flags/ranges/names in its top row (drag moves, end drag sets length, double/right click edits), lanes draw clip markers in the header strip (`lanes/marking.rs`), `timeline/marker_editor.rs` is the popover anchored under `ruler::KEY`, state in `cut/marking.rs` (`Marking` keeps name/note `TextDocument`s committed on blur/submit/close).
- Trims (cut-project `trimming.rs`): `Edit::{RippleTrim { clip, edge, by }, Roll { edit_point, by }, Slide { clip, by }, Extract(span)}` beside `Trim`/`Slip`, with `ripple_limits`, `roll_limits`, `slide_limits`, `slip_limits`, `joint(edit_point)`. Ripple shifts everything from the edit point on every unlocked layer (and timeline markers), limited by the room other layers have; roll beside a gap trims into it.
- Trim UI: `trimmer::Trimmer` (toolbar tiles, Edit ▸ トリム menu); in Select, Ctrl+edge ripples, Alt+edge rolls, Alt+body slips, Ctrl+Alt+body slides. `lanes/trimming.rs` `Trimming` previews its edit through `Cut::preview_edits` (lanes paint the shown project), peeks the edited frame on the stage and labels the delta; `cut/trimming.rs` runs Q/W (extract to the playhead), Alt+Q/W and E.
- Project settings: `Edit::Reformat(Format)` (`reformat.rs`) retimes every frame quantity by exact rational rounding (clip edges, source_in, keys with the last frame pinned, handle speeds, animation presets, transitions, fades, markers, marks) and scales composition by min(w′/w, h′/h) (positions, depth, art, regions, cameras, px effect/animation preset/transition knobs; footage local units by their own fit ratio); it marks the project fitted. `src/reformat/` is the sheet (File menu, status-bar format button), `cut/reformatting.rs` keeps the playhead at the same time.
- `Rate::COMMON` is the one list of standard frame rates (project settings and `cut_export::FrameRate::FIXED`); `Format::aspect` reduces a frame size. Double clicks come from `EventCtx::presses()`.
