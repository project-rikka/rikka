- `Look { world, composite: Arc<Graph>, materials: BTreeMap<String, Arc<Graph>>, slots: Slots, keys: Keys }` is the document value (`.rmotion` kind `look` via `LookFile`). It is GPU-free, names renderer value types only, and never depends on animate-shader. `Look::default()` uses `shared_library()`, a process-wide `library()`.
- `library()` = `rikka_shader_compile::library()` + `world_nodes()` + `with_world(world_outputs())`. World record nodes (`world/nodes.rs`, ids `world.*`) feed World output inputs: `environment` (one of `world.sky`, `world.panorama`, `world.backdrop`, all typed `Record("environment")`), `stage_light`, `lights` (many), `fog`, `shadows`, `occlusion`, `reflections`, `illumination`, `denoise`, `lines`, `particles`, `emitters` (many), `floor`, `sampling`, `characters`, `camera`, `overrides` (many), `rigs` (many). A new list is one more output port plus a node.
- Unwired: optional features (environment, stage light, fog, occlusion, reflections, illumination, lines, particles, floor, overrides, rigs) are off; shadows, denoise, sampling, characters and camera use the node's port defaults. Node docs state each rule.
- Socket conventions: angles in radians (`Hint::Angle`), enums are option indices (`world::Choice` maps renderer and own enums), toggles 0/1, names are asset sockets with `Hint::Text` (figure lists comma-separated), files `Hint::File`. Port names are read back by `World::from_record` (`world/mod.rs` + `world/read.rs`); `tests/world.rs` fails when a port does not reach the typed world.
- `World` (typed) keeps raw node values; `world/render.rs` ports the old stage rules: `look(resolver)` (all but `composite`; liquids always take `LiquidStyle::default()`, the cel style figures had before the toon template went), `lights(focus, eye, &[Linked], resolver)` (stage light as the leading High-shadow sun unless a sky, panorama sun, then `world.light`s with channels and IES profiles), `background()`, `sunlight()` (`LIGHTING_GAIN`), `ambient()` (`AMBIENT_SHARE`), `floor()`, `grid()`, `configure(ViewportConfig)`, `rig`/`drawn_figure`, `overrides_of`, `assets()`. Light units: `LightKind::takes(unit)`, a mismatched unit measures as relative (`measured()`).
- `Resolver` resolves textures, panoramas (texture + `panorama_sun`), IES profiles and override parameter specs by name; overrides convert to the parameter's kind and clamp to its range, unknown parameters are skipped.
- `Slots`: per figure `Name` and material index a `Slot { material: Option<String>, values }`; every edit returns the inverse `SlotEdit`.
- `Keys` = `Tracks<LookKey>` over `Target::{Socket(SocketKey { graph: GraphRef, socket }), Slot(SlotKey)}` with one value channel and a `VmdCurve`; `KeyEdit { removed, added }` builders (`inserting`, `removing`, `moving`, `retargeting`, `dropping`, `renaming_material`) applied by `Keys::apply` return the inverse. Socket key values come from `LookValue::from_socket(value, hint)`: toggles `Bool` and options `Choice` hold, assets `Asset` step, numbers interpolate. `GraphRef`/`SocketKey` live alone in `graph_ref.rs`.
- `GraphRef::{kind, material}`, `SocketKey::edit(value)`; material names pass `check_material_key` (1–48 letters, digits, space, `_-.`), `fresh_name(base, taken)` numbers them. `Look::graphs()` lists every graph.
- Values (`setting.rs`): `value_at(library, target, frame)` (key, else set socket or slot value), `default_value` (port default or parameter default), `set_value(.., Option<LookValue>, frame, curve)` (lays a key when the target is keyed, else sets the socket or slot value), `toggle_key`, `slot_parameter(&SlotKey)`, and `value_from_socket`/`value_to_socket` converting editor `SocketValue`s by port hint or parameter kind (`LookValue::from_parameter`, `to_parameter_socket`, `default_of_parameter`).
- `Evaluated::material_values(figure, material, key, sockets)` gives a slot's renderer values: live graph sockets (keys win) and the slot's own and keyed parameter values, textures as `MaterialValue::Texture { path, kind }` for the stage to load.
- `Look::apply(library, LookEdit) -> inverse`: graph edits and replacements drop tracks whose socket vanished; material insert/remove/rename carry slots and tracks; batches roll back on error. `key_socket` also sets an unset socket.
- Emitters (`world/emitter/`): `world.emitter.{rain,snow,sparks,embers,petals,fireflies,dust,magic,confetti,leaves}` (table `PRESETS` in `nodes.rs`: placement `position`/`yaw`/`pitch`/`roll`, `amount`, `area`|`radius`|`speed`, `wind`, `tint`, `start`/`end`, `seed`) call the renderer constructor then tint, seed and time it; `world.emitter` exposes the full `Emitter` (raw `CustomEmitter`, plus `scale`). End at or before start never ends. Typed as `EmitterLook { node, source: Preset|Custom, placement, track }`; `World::look` builds `Look::emitters` (`at(placement)` when still, else a keyed `EmitterTrack` of `track × preset offset`), sprites through `Resolver::texture`.
- Emitter history (`world/emitter/history.rs`): per plan `Movers::of` finds emitters whose placement steps read `Time` or a keyed socket (`WorldPlan::step` + `Program::reads`); each frame `trace` re-runs only the program prefix (`run_until`) at up to `MAX_TRACK_KEYS` evenly spaced times over [max(t − lifetime, start) − 1 frame, t], keyed sockets sampled at the matching frame, into `EmitterLook::track`. Still emitters cost nothing.
- `Plans` caches world and composite plans per graph `Arc` identity and keyed-socket set; `Plans::evaluate(look, library, frame, time) -> Evaluated { world, composite, records, sampled }` runs only the programs when nothing changed. A keyed socket the graph leaves unset is set in a planning copy (`Look::live_graph`), so keys always drive. `Evaluated::socket(graph, at)` feeds the bridge's `Resolve::socket` and material sockets; `autofocus(distance)` rewrites depth-of-field `focus` when the world's camera autofocuses.
- Defaults: `default_world` (backdrop white, stage light, shadows without contact shadows, shadow-catcher floor with grid, temporal sampling) and `default_composite` (exposure manual 0 → tone map clamp) are bare PMX shading; `cinematic_world`/`cinematic_composite` equal the renderer's `Look::default()` / `Composite::standard()`.
- `world.shadows` port `figures` (`World::figure_shadow`, default High) gives every figure without a rig its own figure shadow map (`drawn_figure`), so figures leave the leading light's cascades; a `world.rig` uses its own `shadow`.
- Files: `LookFile::from_look` / `look(library)` validate every graph (kind and nodes), slots and keys (socket exists, value fits). Paths are relative in files and absolute at runtime through `Look::map_assets(library, map)`, which skips `Hint::Text` sockets.
- Dope sheet: `Sheet::look` groups tracks by `LookGroup::{Node, Slot}` with the node title; animate-timeline names groups `animate.look.track.{world,composite,material,slot}`.
