---
title: Application SDK (sdk/): IDL, codegen, bindings, native library
description: librikka SDK: rikka.ridl object-model IDL, askama codegen per language, committed bindings packages, native C ABI.
about: sdk
tags: [sdk, ffi]
---

- Layout: `sdk/rikka.ridl` (IDL) → `sdk/codegen` (generator) → `sdk/bindings/<language>/` (committed outputs, own package each) and `sdk/native` (Rust implementation, `librikka.so.0`); tests in `sdk/tests/<language>/`, codegen CLI tests in `sdk/codegen/tests/`, runnable examples in `sdk/examples/<language>/` (see the SDK examples note).
- IDL syntax: `library rikka version "x.y.z" abi_prefix rk;` then `const`, `struct`, `enum`/`flags` (`@open`, `@value_prefix(x)`, `@error(success = ok, message = last_error)`), `callback`, free `fn`, and `owned|shared|local|scoped class` (`@builder`) holding `constructor [name](…)`, `fn` (`owned self` consumes), `[readonly] property`, and `container|element|modifier` view declarations (scoped classes only). Params borrow unless `owned T`; results own unless `borrowed T`; `[T]` arrays; `(a: cb, b: cb)` closure groups; `@any_thread`, `@thread_safe`; `throws <error enum>`.
- Docs are `///` with `@param`, `@returns`, `@set` (property setter) and cross-references `[name]`/`[type.member]`, resolved by the model and rendered per language (C `rk_x()`, C++ `rikka::X::y()`); stale references fail generation.
- Codegen pipeline: `syntax/` (lexer + recursive descent → AST with spans) → `model/` (symbols, validation, `Api` with typed `Id<T>` arenas) → `abi.rs` (C ABI: names `rk_<class>_<member>`, `_new[_name]`, `_set_x`, `<container>_begin`, `end`, `_free/_ref/_unref`; receiver slot = last word of the class name; arrays add `<name>_count`; closures add `userdata`, `destroy`) → `languages/{c,cpp,rust,go,csharp,java,python}` (each a `Language` in `language.rs`'s table, spelling + view models + `templates/<language>/*.j2`). Errors are `path:line:col: error:` diagnostics with a caret.
- `rikka_bindings(name, language, outs, committed)` in `//sdk/codegen:defs.bzl` runs the codegen with the declared outs (the binary refuses undeclared or missing files) and diff-tests `generated/<out>` against `<out>`; `bazel run //xtask -- sdk` copies every output of `//sdk:bindings`. The Rust export layer (`src/ffi.rs`, generated by the `ffi` rule of `sdk/native/BUILD.bazel`) is build-time only.
- C++ projection (`//sdk/bindings/cpp`, header-only C++20 over `//sdk/bindings/c`): PascalCase types, snake_case members, `name_` for keywords; owned = move-only RAII, shared/local = copyable refcount, scoped = non-copyable lent `View`/`Context`; `adopt/raw/release` interop; builder setters drop `set_` and are `&`/`&&` chainable; `throws` → `rikka::Error`; closures are any callable (concept-constrained, `noexcept` trampolines over `std::tuple` packs); containers take a body lambda and return `Element`, whose methods are the modifiers.
- Native side: generated exports call safe `crate::api::<abi name>` fns in `sdk/native/src/api/*` through `crate::abi` helpers (`enter`, `text`, `enumerated`, `owned_mut`, `take_owned`, `shared_ref`, `local_ref`, `scoped_mut`, `slice`, `Closure::new`, `give_*`, `lend`); violations print `rikka: <fn>: <message>` and abort. Lifetimes map to Box (owned), Arc (shared), thread-tagged Rc (local) and callback-scoped pointers (scoped).
- `sdk/native/src/view` builds a frame stack of `Node { kind, common, children }`; modifiers hit the last begun or ended node, item containers admit only their items, and lowering at view end turns sheets into a scrim plus centred panel, anchors popovers and popup menus, and wraps context menus and shortcuts. A window is `rikka_app::Window<Model>`; `memo` maps to `lazy`, `post`/`invalidate` use its `Sender`. Icons are Material Symbols names.
- Drops: `on_drop_files`/`on_drop_text` fill `Common::drops`, lowered by wrapping the element in a `drop_zone` (`view/drop.rs`); the offer is read in `spawn_blocking`, local `file://` URIs go to the files callback, else text. Pictures and videos get min size 0, so their natural size never forces overflow.
- Dialogs: `context.alert/confirm` queue into the window's `Dialogs` (`window/dialogs.rs`, `Rc` shared by `Model` and `Context`); `render` appends the front one as scrim plus `alert_prompt`/`confirm_prompt` (rikka-widgets) centred on `STAGE`.
- Media (`sdk/native/src/media`): `sound` streams through one process-wide `rikka_audio::AudioEngine` (recreated after device loss), opened on a `rikka-sdk-open` thread by `Voice::open_for`; `video` wraps a `rikka_movie::Movie` (its picture opens once a view draws it; `App` and the embedded host install a `rikka_ui_video::VideoStore`) whose `MovieEvent`s mark separate state and position `Observers` and notify `on_end` listeners through the window's `Sender`, so video needs no tick; a playing video holds itself strongly until it pauses, ends or fails, so fire-and-forget playback continues. A missing file fails at construction. The ffi object wraps `Arc<core>`; `sound` watches its handle (`PlaybackEvent::Progressed` marks position, `Finished` reopens the stream paused at 0 and notifies `on_end`), and a playing sound holds itself strongly until it pauses, stops, ends or fails, so no media tick or playback thread remains.
- `open_url` requires an absolute URL without whitespace; `open_file` absolutizes, checks existence and opens a `file://` URI through `rikka_open::open`.
- Embedding: `vulkan_device` (host handles, extensions, features chain address, submit closure group wait/execute/signal) → `embedding` (check `error_message` before `open`; `set_theme(slug)`/`set_background(theme_background)` override the desktop's look, empty/`desktop` follow it) → `embedded_surface` (resize, `render(vulkan_image)`, input functions returning whether they were used, `type_text` for produced text vs `key_press` for named keys and chords, `cursor`, `caret`, `leave`/`rejoin` with builder `on_left` and `view.is_leaving`). Native side in `sdk/native/src/embedding/`, input conversions in `src/input.rs`; surfaces reuse the window `Model`, so `context.window` posts to them. View modifiers `position`, `scale` and `glass` serve them too. The Java codegen pads struct layouts to C alignment.
- `theme_catalog` (`sdk/native/src/api/theme.rs`) lists `ThemeRegistry::discover` (Rikka's themes, then Material You, then installed) with slug, name, darkness and solid palette colours. `scrim` is an unanchored `rikka_widgets::scrim` over its parent that fades by default. `corner_*` consts mirror `rikka_theme::Corner`. A type name may not equal a C function name (`rk_background` clashed, hence `theme_background`).
- Install ships `lib/librikka.so.0` (`//sdk/native:versioned`), `include/rikka/rikka.h`, `include/rikka/rikka.hpp` and `lib/pkgconfig/rikka.pc`, plus the Go, C#, Java and Python packages under `share/rikka/sdk/<language>/` (see the SDK language bindings note).
