- `animate-cloth` (private, GPU-free): `Surface` (CPU-skinned posed or rest render mesh in `ClothAnalysis` vertex order, ray cast, sphere footprint with falloff), `Mirror` (rest-space X=0 twin per vertex), `Brush`/`Tool`/`Dab` (paints roles or eases spread into a `ClothSettings`), `Knob` (the three `ClothTuning` sliders: sway, response, weight), `Field`/`Section` (macro table over every `Style` field with ranges and units), and `preset_id`/`kind_id` names shared with the assistant.
- `cloth::Cloth` sits on each cast `Figure`: model path, current and saved `Arc<ClothSettings>`, the latest `ClothAnalysis` (or its error; `None` until the first survey lands), an edit counter and the `Mirror`. Arrival loads the `.rcloth` sidecar beside the model; `Figure::load` returns a `LoadedFigure` (mapping error only) whose `Cloth` is still analysing (edits 1, analysed 0) and whose `physique` is `None`; a bad sidecar arrives as a `Rejection::Unreadable` notice and an empty cloth settings.
- Progressive arrival: `accept` shows the figure at once and calls `Animate::survey`, which runs `animate_cast::Survey` (analysis + `fit_physique`) on a `rikka-animate-analysis` thread; `finish_analysis(Surveyed)` adopts it only if no newer edit came, shows it on the stage and `refit`s (rebakes the playback when the `Physique` changed). Pending analysis behaves like an absent one: no cloth assets, unfitted bakes. A body-fit failure arrives as the `wording::body_fit` notice; the figure then has no `Physique`.
- Exports wait for surveys: `Job::start` spawns the export thread, which waits for `Job::stage(replica)`; `Animate::stage_export` sends the replica once no figure `is_analyzing` (also called after every adopted survey), and cancelling drops the waiting sender.
- Every change goes through `Animate::apply_cloth_settings(id, Arc<ClothSettings>)` (also used by piece edits and the assistant): it records `Edit::Cloth(Pair)` under `Subject::Figure`, pushes the cloth settings to the stage and re-surveys on a `rikka-animate-analysis` thread whose answer lands through the window `Sender` only if no newer edit came (`Cloth::analyzed`). `analyze_now` analyses synchronously for the assistant.
- The figure-wide tuning (`ClothSettings::tuning`) is edited by `set_figure_knob`/`reset_figure_tuning` and works on top of every piece's style. Piece edits (`set_preset`, `set_knob`, `set_field`, `set_piece_enabled`, `set_layer`, `reset_piece`) edit `PieceSettings` via `ClothSettings::settings_mut`; a preset or feel change drops detailed `style`, a field edit stores the whole resolved `Style`. `cloth::Garment::of` derives what the UI shows from the cloth settings, not the possibly stale analysis. Re-detect clears all paint.
- Save: File → Save Cloth (`Command::SaveCloth`) or the tab's Save button writes the sidecar (adopting current piece keys); saving is enabled only for figures read from a file with unsaved changes.
- Stage (`animate-stage` `cloth/`): `figure_cloth` per figure (`FigureCloth { cloth_settings, analysis, mirror, revision }`, `Stage::figure_cloth_for`), `cloth_quality`, and a `PaintSurface` (posed `Surface` + view-projection + eye, `Stage::paint_surface`) built in `Stage::build` for the chosen figure while the Physics tab's painting section is open (`Animate::paints_cloth`, `fit_cloth`). Integrator hooks: `Stage::set_cloth_settings(figure, settings, mirror)` (bumps `FigureCloth::revision` on every new settings), `show_analysis`, `set_cloth_quality`. Replicas copy them.
- Quality persists as `cloth-quality` (low/medium/high) in `rikka.animate` (`preferences/cloth.rs`).
- Viewport: with the Physics pane's painting section open (`Controls::painting`, `show_painting`) and a figure chosen, `Aim::Cloth(ClothAim)` makes a left press that hits the mesh start a `Stroke` (misses orbit the view); the brush radius is screen pixels converted at the hit depth, Ctrl erases, and release sends `Gesture::Tailor`. `animate-viewport` `cloth/paint.rs` draws front-facing vertices thinned to one per 4 px cell, coloured by role (painted role over analysis role), the chosen piece in yellow, spread as a ramp while the Spread tool is on, plus the brush ring.
- Inspector (`animate-inspector` `inspector/physics/`): simulation card (physics switch, reset, quality), figure header with Save, the whole-figure tuning card, pieces (kind icon, select, enable, preset, layer), the chosen piece's Easy tuning sliders (animate-inspector `inspector/physics/tuning.rs` `Tuned::{Figure, Piece}` shares the rows, drafts keyed by `Dial::{Figure, Piece, Field}`) or, in Detail mode (Ctrl+E), every style field with `DepthCurve` point editors for depth curves (press adds, drag moves, right-click removes), then the collapsible brush painting section.
- Assistant tools `Cloth`, `SetCloth` (whole-figure `feel` and/or pieces by name: preset, enabled, feel, reset), `Wind`, `SetWind` (resting, keys, clear); each call is one undo step.

## GPU cloth in the stage (`animate-stage` `physics/`)

- `Simulation` owns a lazily woven `LiveCloth` (gravity 7.84 m/s², floor 0, one tailor `Quality::{Low, Medium, High}` for the cloth builder and `Budget::from`), keyed by `FigureId::slot()`; physics off or a quality change drops it.
- Only figures whose pushed analysis has an enabled piece get a cloth asset. `Stage::request_cloth_assets` asks `cloth_assets.rs` (`ClothAssets`, one `FigureAsset` per figure) (worker thread `rikka-animate-tailor`, latest order per figure wins, stale revisions dropped, failures remembered per revision). A cloth settings that `ClothSettings::same_topology` the worn one (only feel/style differ) is restyled from a fresh `ClothAnalysis` and applied with `LiveCloth::set_style` instead of re-cut; a thickness change re-cuts.
- `settle` follows the timeline (`Pace::Playing` / `Pace::Stopped { idle }`) through `physics/posing.rs` `Posing` (the `LivePose`): each cloth step re-animates the actors at its own time and computes that time's grabs; afterwards the actors are held at `LiveCloth::posed()`, so a playing figure is drawn up to one cloth step behind the clock, consistent with its cloth. `stillness.rs` stops stepping after `motion()` stays below 0.03 m/s for 0.5 s; time, pose, wind, cloth asset and physics edits stir it. The render thread publishes `restless` (busy cloth assets, unsettled cloth, waiting captures) for `Stage::next_draw`. Once the pose holds, the cloth's own `Rest` damps and then sleeps it (motion 0), which is what lets a stopped stage settle.
- `compose` drapes every figure from the liquid `SceneFrame::drapes` when it has drapes for it, else from the `LiveCloth`. The `LiquidScene` gets a `ClothScene` (cloth builder + current cloth assets; a change re-bakes from step 0). With `Playback::Simulated` and taps the `LiveCloth` is not stepped.
- `stage::replica` copies the worn cloth assets; `pose_at` (captures, exports) leads in from up to 2 s before a frame that does not continue the last one, so exports from frame 0 match the viewport step for step.
