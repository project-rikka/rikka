- Runs only for frames with `Frame::look`; without one `sky.slang` draws the old gradient and `rikka.sky` returns `view.ambient`.
- `Look::environment` picks the source: `Environment::Sky` (everything below), `Environment::Image(EnvironmentImage)` (an equirectangular linear HDR texture, top row up, centre column −Z, `rotation` yaw about +Y) or `None`. Both sources fill the same SH9 buffer and prefiltered atlas, so `rikka_sky_irradiance`/`rikka_sky_specular` consumers (shading models, SSR misses, ray escapes, water, fluid, particles, fog ambient) never know which; an image synthesizes no atmosphere, aerial perspective, sun or moon.
- Panorama passes (`sky/panorama.rs`, `sky_panorama_*.slang`, module `rikka.sky.panorama`): capture box-averages the source (solid-angle weighted, luminance clamped to `sun_clamp`, scaled by intensity·tint, capped at the half-float maximum) into level 0 (512×256) of the shared `rikka.three.sky.panorama` atlas, reduce fills levels 1–7 below it; harmonics projects level 2 with exact texel solid angles and applies a sinc⁴ window only as narrow as needed to keep the irradiance non-negative; prefilter writes the usual octahedral atlas with GGX importance sampling and PDF-based lod selection (no fireflies). Capture reruns when texture, scale or clamp change (`SkyState::captured`), harmonics/prefilter also on rotation.
- The panorama background is `sky_panorama.slang` (premultiplied over, so `background` blends over `Background::Color` or transparency), drawn for `Background::Sky` or `Color`: the source texel-loaded at `blur` 0, else the prefiltered chain at roughness `blur`. Sky pixels reproject with `RikkaScene.previous_sky_view_projection`, which folds the rotation change since the viewport's last frame (`ViewHistory::environment_rotation`).
- Sun extraction is CPU-side: `Panorama::new(w, h, &rgba_f32).sun(threshold)` returns `PanoramaSun` (direction in map frame, luminance-1 colour, illuminance in renderer units per unit intensity, disc-equivalent angular radius) for the energy above `threshold`; `PanoramaSun::light(&image)` is the matching shadowed directional light, used with `sun_clamp: Some(threshold)`.
- `sky/images.rs` declares the sky images: renderer-wide LUTs and environment as shared graph images (`look_state.images`), per-view aerial, fog and shafts as transients; `SceneImages::publish` writes their slots into `GpuSky`.
- `atmosphere` group: transmittance 256×64 → multiscatter 32×32 (64 threads per texel) run only when haze or ground colour change or the shared tables lost their content (`SkyState::tabulated`, `holds_shared`); sky-view 256×128 (world azimuth, sun+moon+airglow, alpha = grey view transmittance) → SH9 into `studio.environment` → octahedral base 128² → prefiltered atlas 192×128 (6 GGX levels, level k at x=128,y=128−2·(128>>k)) run when sky, fog or time change (`SkyState::lit`); aerial 32³ tiled 8×4 every frame.
- SH order and the irradiance/π convention are fixed by `shaders/lib/rikka/sky.slang`; the sky's SH kernel adds the ground hemisphere analytically.
- `fog_volume` (after shadows): one thread per froxel column (12 px tiles, 64 log slices 1–256 m, tiled 8×8) integrates height fog lit by SH ambient, horizon sky and all lights with shadow-atlas lookups.
- `fog` post filter: aerial perspective on geometry, analytic height fog beyond 256 m (sky pixels to 2 km), the fog volume, then screen-space shafts from a quarter-res radial occlusion pass toward the brighter of sun and moon.
- Atmosphere is in kilometres; `look/atmosphere.rs` (CPU transmittance for the celestial lights) and `shaders/lib/rikka/sky/atmosphere.slang` must keep identical constants. World units are taken as metres (`RIKKA_WORLD_TO_KM`).
- Clouds are a procedural 2 km layer shared by `sky.slang`, the environment map and the SH (`rikka.sky.clouds`, `rikka.sky.dome`); stars use `Sky::star_rotation()` so they turn with the hour.
- Every `Record` method here starts with `sky_`; generic helpers stay free functions in `sky/kernel.rs`.
