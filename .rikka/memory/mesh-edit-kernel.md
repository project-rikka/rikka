- Public crate `rikka_mesh_edit`; `EditMesh` is the Edit Mode form of `rikka_polymesh::Polymesh` (`from_polymesh`/`to_polymesh`, lossless, order-stable). Operator crates use only its API.
- Radial-edge topology: `VertId/EdgeId/LoopId/FaceId` (u32 slots, `ElementId` trait) index arenas; killed slots are reused LIFO (the reference mempool order, so construction sequences reproduce the reference's element order). Ids stay valid across unrelated edits; check `contains_*` before reusing ids after kills. `compact()` returns a `Compaction` (`map_vert`… old→new) and orders loops face by face.
- Navigation mirrors the reference mesh: `vert_first_edge`, `disk_next/prev(e, v)`, `edge_verts`, `edge_first_loop`, `loop_{vert,edge,face,next,prev,radial_next,radial_prev}`, `face_first_loop`, `face_len`; iterators `vert_edges/loops/faces/verts` (`vert_loops`/`vert_faces` in the reference loop order), `edge_loops/faces`, `face_loops/verts/edges`, `loop_cycle` (disk and radial orders match the reference's). Queries in the reference mesh vocabulary (`is_edge_manifold`, `edge_other_loop`, `face_other_vert_loop`, `vert_step_fan_loop`, `edge_face_angle_signed`, `face_center_median_weighted`, `face_tangent(FaceTangent)`, `volume`…).
- Scratch state: `IdSet<I>` (bitset, index-order iteration), `IdMap<I,T>`, `Marks<I>` (8 independent bit layers per element), `LocalSet<T>` (small inline set for a few ids), plus the transient `Flags::TAG` (`set_*_tag`, `clear_tags`; no revision bump). `Geometry` bundles three `IdSet`s for operator inputs/outputs.
- Shared reference utilities live here so operator crates never copy them: `Heap`/`HeapNode` (reference heap order) and `SimpleHeap` (reference heap simple), `ScanFill` (reference scanfill), `Rng` (reference rng), `pub mod math` (reference math in the reference's float order: normalize*, angle*, ortho/axis projection `AxisProjection`, newell, beauty costs, `intersect_*`, `turbulence`, `uv_equal`/`color_equal`…), `Falloff`, `MathLayer` (corner UV/colour layers, `is_edge_contiguous_loop_data`), `EdgeLoop` (BMEdgeLoopStore: `find_edge_loops`, centre/normal, `expand`/`expand_split`, `calc_order`), `beautify_fill(BeautifyFill)`, `split_face_edgenet` + `split_face_edgenet_connect_islands` (the reference routine, sets real disk starts), `weld_verts(WeldOptions)`, `recalc_face_normals`, `calc_face_groups`/`calc_edge_groups`, `verts_normal_from_cloud`, `topology_mirror`/`topology_mirror_table`, lnor spaces (`NormalSpaces`, `EncodedCustomNormals`, `corner_normals`, fan walks), flag merging (`Flags::merge(_hidden)`, `merge_*_flags`, `set_*_flags`).
- Flags: `SELECT`, `HIDDEN`, `SEAM` (edge), `SHARP` (edge, default off = smooth), `SMOOTH` (face, default off = flat, so new faces are flat like the reference), `TAG`; material is per face (`face_material`). Raw `set_*_flag` does not flush; use `select_*`/`hide_*` for the reference flushing.
- Data: every Polymesh attribute lives per slot in its domain (`attribute::<T>(name, Domain)` slices indexed by `id.index()`), plus vertex-group influences and shape-key layers (`key_blocks`, `key_positions`). Never name layers in operators: use `copy_*_data` (the reference routine: everything but SELECT), `interpolate_*_data(&[(id, w)], to)`, `interpolate_*_data_between(a, b, to, f)`, `average_*_data`, `interpolate_face_vert_edge`, `copy_face_loop_data_shared`. For loop data from a face use `sample_face(f) -> FaceSample` (captures positions, normal, loop and vert rows) then `interpolate_loop_from_sample`/`_face_from_sample`/`_vert_from_sample` (2D mean-value weights, the reference routine semantics); sample before mutating the source face.
- Creation: `add_vert(_like)`, `add_edge(_like)`, `ensure_edge`, `new_face(&verts).example(f).reuse_existing().existing_edges().match_winding().create()`, `add_face_from_edges`, `copy_face`. Kills: `kill_vert/edge/face` cascade like the reference mesh, `kill_face_loose`, `kill_face_edges/verts`, `delete(DeleteContext, &Geometry)` = the reference routine.
- Euler/mods (all `Result`, return created elements): `split_edge_make_vert`, `split_edge(e, v, f)`, `split_edge_n`, `join_edge_kill_vert(JoinOptions)`, `join_vert_kill_edge`, `collapse_edge(_at)`, `collapse_vert_edge/faces` (the reference routine with loop/vert interpolation, joins reuse doubles), `split_face_make_edge`, `split_face`, `split_face_n`, `connect_verts`, `join_faces_kill_edge`, `join_face_pair(_keep_shared)`, `join_faces(_keep_shared)(&[f], DoubleFace)` (the reference routine with/without do_del), `face_find_double` (the reference routine), `splice_verts/edges`, `separate_vert(v, &edges)`, `separate_edge`, `separate_loop_region(_multi/_isolated)`, `reverse_face`, `rotate_edge(Rotation, RotateChecks)`, `dissolve_vert/disk` (the reference routine), `triangulate_face(QuadMethod, NgonMethod)` (quads follow the reference routine exactly; original face keeps the last triangle), `set_vert_first_edge` (disk start); `new_face(..).edges_from_previous()` creates missing edges in the reference routine order, `duplicate(&Geometry) -> Duplicate` maps. Faces below 3 corners are always killed.
- Normals are cached and explicit: `update_normals()` (parallel), `update_normals_around(moved verts)` (parallel per face/vert list; a quarter of the mesh or more runs `update_normals`), `calc_face_normal` (the reference mesh tri/quad/Newell). Revisions (`revisions()`: mesh stamp + topology/shape/selection/data/keys counters; `keys` bumps on key-array or active-key changes) bump on every mutation; clones get a new stamp. `tessellate()` (parallel) gives looptris + face map; `Tessellation::update(mesh, moved)` refreshes moved faces or rebuilds after topology changes.
- Change journal: `journal_mark()` / `changes_since(mark) -> Option<Changes>` list vertices passed to `set_position`/`translate` (`moved`), elements whose SELECT/HIDDEN bits changed since the mark, and custom-normal corners written by `set_custom_normals` (`corners: Option<&[LoopId]>`, own epoch: bulk writes over 1/8 of the corners and corner overflow make only `corners` `None`). Entries may repeat, never miss. `None` means unknown: topology changes, `positions_mut`, key edits, other bulk shape writes, clones and overflow (more than max(65536, capacity/8) element entries) start a new epoch. Every SELECT/HIDDEN write inside the crate goes through the journaled `put_*_flags`/`mark_*` helpers; new code writing those bits must too. Consumers (render bridge, undo records, pick refits, cage deltas) keep their own marks and fall back to a full scan on `None`.
- Custom normals (`lnor.rs`): `set_custom_normals(&[(LoopId, Vec3)])` is a journaled shape change (bumps `shape`, not `data`; `custom_normals_mut` still bumps `data`). `NormalSpaces` keeps the fan structure (recipe per fan: single corner or walk start) and the edge smooth flags, so `update_around(mesh, moved)` recomputes only fans whose pivot is a vertex of a face around a moved vertex (a superset of the reference's equivalent set: quad diagonals and the zero-normal `vert_normal` fallback need it) and `sync(mesh)` catches up from the journal (rebuild when mesh stamp, topology or data changed). `EncodedCustomNormals::capture`/`capture_with(mesh, spaces)` encode once per drag and remember corners whose stored value is not yet the decoded one; `restore_around(mesh, moved)` writes exactly what a full `restore` would (bitwise; `rikka-mesh-shape` `custom_normals::partial_restore_matches_full_restore`); `into_spaces` hands the spaces back. Spaces, encode and decode are parallel; a region of a quarter of the vertices or more refreshes every fan.
- Selection follows editmesh: `set_select_mode`/`change_select_mode(mode, expand)`, `select_vert/edge/face` flush rules, `select_mode_flush(_down)`, history (`history_store`, `set_active`, `active_element`), `hide_*`, `hide_selected`, `reveal`. Operators: `select_all`, `select_more/less`, `select_linked(_pick)`, `pick_loop`, `select_edge_loops/rings`, `select_boundary_loops`, `select_loop_inner_region`, `select_region_boundary`, `select_shortest_path(PathOptions)`, `select_similar_{verts,edges,faces}` (+ `similar_*_value`/`selected_similar_*_values` keys and `select_similar_*_matching(refs, matrix)` for multi-object world space), `select_similar_region` (bmesh_region_match via `region_match`), `select_random`, `deselect_checker(Checker{deselected, selected, offset})`, `select_non_manifold`, `select_loose`, `select_interior_faces`, `select_faces_by_sides`, `select_sharp_edges`, `select_linked_flat_faces`, `select_mirror` / `select_mirror_mapped(axes, extend, Option<&IdMap>)` (topology mirror), `select_by_material`, `select_verts_where`, `select_vertex_group`, `select_ungrouped`, `select_next_active`/`select_previous_active`.
- Walkers take `Walk { skip_hidden, delimit: WalkDelimit, verts/edges/faces masks }`: `walk_edge_loop`, `walk_edge_ring`, `walk_face_loop`, `walk_boundary`, `walk_non_manifold_loop`, `walk_island(_delimited)`, `face_islands(LinkedDelimit)`, `walk_connected_verts`, `walk_uv_edge_loop`; paths `shortest_path(_verts/_edges/_faces)` and `path_region`.
- Shape keys follow the reference routine: vertices show the active key; writing back offsets keys that depend on the active key unless any vertex was created from an example (`is_vert_original`; `set_vert_original` restores that state, bumping `keys`). `from_polymesh` marks every vertex original, so anything rebuilding an EditMesh from a polymesh (undo) must re-mark created vertices.
- `add_primitive(&Primitive, Mat4, calc_uvs)` builds the reference's primitives (plane, cube, circle/cylinder/cone with `CircleFill`, grid, torus, UV and ico sphere) with the reference's UVs; UV/ico sphere vertex order differs from the reference, geometry and UVs match.
- `validate()` checks every structural invariant; tests call it after each operation. Oracle data comes from the reference scripts (`tests/oracle.rs`, values in millionths).
- Every layout mutator bumps a revision (vertex groups, active group, active/render UV and colour layers: `data`; `key_blocks_mut`: `keys`); modeler-document history keys its layout records on these, so a missing bump makes undo skip the change.
