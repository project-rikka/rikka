- `Look::composite: Composite { nodes: Vec<CompositeNode { key, operation, inputs: Vec<(String, CompositeInput)> }>, output }` replaces the fixed post chain. `CompositeInput::{Layer(RenderLayer), Node(index)}`; a node reads only smaller indices. `Composite::default()` = `standard()` (Exposure → MotionBlur → DepthOfField → Glow → Grade → Tonemap → Lens), `passthrough()`/`new()` have no nodes and output `Layer(Image)`; `push(op)` wires `image` to the last node (or `Layer(Image)`) and makes it the output, `node(op, inputs)` adds without touching the output, keys default to max key + 1.
- Module map: `composite/mod.rs` (public types, builder), `operations.rs` (Exposure/Metering, MotionBlur, DepthOfField, Glow, Grade, Tonemap/Tone/AgxLook/ToneCurve, Lens), `plan.rs` (`CompositePlan`, per frame in `FrameScratch`: validation, reachability from `output`, reads, exposure contexts, native and effect parameter blocks in the `rikka.three.effects` buffer), `layers.rs` (`LayerImages`: presenting layers, `RenderLayer::Previous`), `declare.rs` (declares reachable nodes in index order). Native passes live in `src/post/` (`exposure`, `motion`, `focus`, `glow`, `finish`: grade, tonemap, lens, present); `PostState::recipe(Pass)` holds their fragment programs.
- Validation (`Error::Invalid`, per frame, every node): duplicate keys, unknown or twice-wired sockets, missing required sockets (`image`; every `Effect::input`, while `Effect::optional` sockets may stay unwired and reach the shader as `RIKKA_NONE`; an effect's first socket is always required), links to the same or later nodes, output out of range, disabled effects without inputs; unknown effects are `Error::Unknown`. Only reachable nodes are planned, so parameter errors (`Error::Parameter`) and every pass, image, emission/layers attachment and history come only from reachable nodes (`Reads { emission, layers, motion, previous }`).
- Sockets: every native has `image`; Glow also optional `source` (`Glow::SOURCE`; wired source makes the bloom additive, unwired glows the image with the old mix). Effects declare sockets with `Effect::input(name)`; built-ins have `image`. A disabled effect passes its first socket through.
- Links are display-sized RGBA16F: scene-referred linear until a Tonemap, then sRGB-encoded premultiplied. Layers: `Image` = resolved scene after temporal/RCAS; `Depth` = display R32F reversed depth (nearest-upsampled, as effects read it); `Normals`/`Velocity` = decoded `effect_surface`; `Layers` = RGBA mask of layer bits 0–3; `Emission` = display-sized emission exposed by the reading node's exposure context; `Occlusion` = AO in rgb (white when off); `Previous` = last frame's composite output (history `rikka.three.composite.previous`, key 0, copied by `keep_output`; the current `Image` on fresh history, cut or resize). Conversions run through `shaders/composite_layer.slang`.
- Exposure: Auto meters its input (history `rikka.three.post.exposure` keyed by node key; histogram of log luminance between `low_percentile` and `high_percentile`, centre-weighted by `center_weight`, figure pixels weighted by `figure_metering`, adapted target clamped to `darkest..brightest` EV) and multiplies; Manual multiplies by `exp2(compensation) · frame.exposure`; Physical is absolute: `Exposure::ev100()` = log2(N²/t) − log2(S/100) from `aperture`, `shutter` (s), `iso`, and `physical()` = NITS_PER_RADIANCE_UNIT · 2^compensation / (1.2 · 2^EV100) (saturation-based sensitivity). `exposure::fixed` gives the Manual/Physical value for both the node and the temporal resolve. A node's exposure context is the nearest Exposure up its primary (`image`/first) socket chain; Grade's night shift and Glow's sun flare use it. Downstream thresholds (bloom, DoF highlights, streaks, EV effects) are relative to their input. The temporal resolve uses the first reachable Exposure's last-frame state and the first Tonemap's tone (`Tonal::metered/graded`).
- Tonemap: `Tone::{Gt, Agx, Aces, Neutral (Khronos PBR Neutral), Clamp, Hable (Uncharted 2, W 11.2, bias 2), Reinhard (Jodie), Lottes (2016 defaults), Custom (Uchimura curve from `ToneCurve { peak, contrast, toe, linear, toe_power }`, equal to Gt at defaults)}`; `AgxLook::{Base, Punchy (default), Golden}` applies a CDL look in AgX log space; `preserve_hue` (0..1) mixes in a mode that maps luminance through the curve, keeps the RGB ratios and desaturates toward the mapped grey only where a channel would clip. Option lists in rikka-shader-compile only append (Animate stores indices). Code: `shaders/lib/rikka/post/tone.slang`, `post_tonemap.slang`, `post/finish.rs`.
- Grade is scene-referred; lift/gamma/gain/tints/black act on a Reinhard-compressed view (skipped at defaults). Lens is display-referred (sharpen, chromatic aberration, vignette in decoded light, grain). `rikka.three.present` (`composite_present.slang`) dithers, adds the selection outline and writes the output texture. Frames without a look keep `tonemap.slang`.
- Effect history keys by node key, so reordering keeps histories. Tests: `tests/look/composite.rs` (wiring, validation, pruning, history keys, Previous trail, exposure), `effects.rs`, `effect_pack.rs`, `filters.rs`, `glare.rs`, `grading.rs` (tone curves vs reference formulas, hue preservation, CDL, white balance, EV100), `feedback.rs` (trails, frame blend, datamosh); `canvas.rs` is their shared pattern-painting harness (runtime-compiled pattern effect, Clamp tone map, sRGB decode).
