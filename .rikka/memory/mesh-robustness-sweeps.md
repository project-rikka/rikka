- `crates/model/rikka-test-meshes` (testonly, visible to `crates/model` and `apps/general/modeler`) holds `corpus()` (empty, loose, wires, ico triangles, triangulated blob, mixed tri/quad/n-gon, concave/non-planar n-gons, fin, bow-tie+wires+loose, doubled faces, faces sharing all verts, open grid, degenerate, coincident, every-data-layer mesh) and `sample_fixtures()` (300-face patches of miku.pmx, avatar.vrm, fox.glb loaded through the codec importers; files come in as library `data`).
- `sweep_edit(name, fixtures, cases, &[(name, EditOperator)])` runs each `fn(&mut EditMesh, &mut Rng) -> Result<(), String>` over seeded `Selection`s (mode × empty/single/partial/all × hidden), accepting `Err` as a note and checking `check()` (validate, layer lengths via `to_polymesh().validate()`, no NaN from finite input). `sweep_chains` runs random operator sequences; `replay_chain` + `python_dump` reproduce a failing chain step and dump it for the reference script.
- `Sweep` catches panics with location (also echoed to stderr, since a panic that kills the case process would otherwise vanish), prints slow cases (>1 s), aborts naming the case after 20 s (watchdog), and `tolerate(prefix)` downgrades a known failure to a note (no modeler sweep tolerates anything). `Amount::pick`/`choose` pick empty/single/partial/all subsets of any list.
- Each operator crate keeps its sweep in `tests/robustness.rs`; UV sweeps also live there (`UvSurface::from_polymesh`, `seamed_grid` for thousands of single-face islands); the modifier sweep compares `evaluate_cached` (cold and after nudged positions) with `evaluate`.
- `apps/general/modeler/crates/modeler-test-sweep`: `OperatorSweep::new(name, operators, Editor).prefixes(..).skip(..).view_only(prefixes).property(name, Value).generated(name, fn(&Document, &mut Rng) -> Option<Value>).switches(&[Switch]).round_trips(dir).cases(n)` then `.run(fixture worlds)` (edit-mode worlds), `.run_scenarios(&[Scenario::new(name, Editor, build_fn)])` (every operator × cases, result undone after each) or `.run_sessions(scenarios, count, length)` (random interleavings of polling operators, mode switches and activations, results kept; a session stops past 6000 faces). Before each call it randomizes edit-mesh, edit-bone, pose-bone or object selection and pushes a step.
- Invariants per call: no panic; Finished, or Cancelled/PollFailed/failed call with the `DocumentState` bit-identical and no step; `view_only` operators change nothing and push nothing; any pushed step(s) undo (`jump` back) to the exact previous `DocumentState` and redo to the result; an UNDO operator that changes state must push; scene, meshes, edit meshes and edit armatures validate and every mesh object evaluates; a replaced document (file ops) is adopted; every 40 cases `.rmodel` save-copy and reopen gives the same scene (image storage ignored), settings and extensions.
- `DocumentState::capture(&Document)` (public, also used by modeler-document and operator crate tests) = modes, encoded scene with edited meshes blanked, encoded tool settings, extensions, encoded edit armatures, loaded image pixel digests, and per edit mesh the canonical `to_polymesh` plus raw positions, raw key layers, active key, non-original vertex ranks, select mode, history and active face by rank; `difference()` names the first mismatch.
- App-level sweeps live in `apps/general/modeler/crates/modeler-app/tests/sweep/` (all `REGISTRATIONS`): a rig scene (armature with constraints, skinned grid, keyed `layers` mesh, sample patches) in Object/Edit armature/Pose/Weight/Vertex/Texture Paint, Image and Outliner editors; VRM/PMX authoring on the opened sample files; `wm.*` with filepaths in a scratch dir; multi-mode and multi-object sessions.
- Rule for degenerate input: where the reference's maths overflows (UB or NaN) the port follows the reference's observable result when it is finite (e.g. data-transfer ray counts emulate the C cast to INT_MIN) and otherwise takes the nearest defined branch (bevel `line_line` treats non-finite meets as parallel; circularize falls back to the centroid/mean-radius circle when Gauss-Newton diverges or a closed loop's centre leaves its extent).
