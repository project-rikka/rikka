description: A caret-placed overlay over committed Unicode/CLDR data that types or copies the chosen emoji.

- `rikka.emoji` = `PresenceService` + `insert`. It opens on the `emoji-picker` shortcut (`Super+.`).
- `insert` hides first, then types from `Presence::after_unmap` once the picker surface is destroyed, falling back to the clipboard when typing is off or unavailable.
- Data and search live in the shared `crates/foundation/rikka-emoji`: `data/emoji.txt` (CLDR order, group, five tones) and `<locale>.txt` names, generated by `xtask emoji-data`. The pinned version must stay within what Noto Color Emoji draws.
- Only base emoji are listed. The tone is a column applied on show and insert.
- `rikka_emoji::Catalog::current()` is kept per language; it merges locale and English names, adds the English snake_case `code` as a keyword, and folds hiragana to katakana. The shell keeps only group labels and symbols (`group.rs`).
- Ranking: exact name > name prefix > exact keyword > contains. Every query word must match.
- Recents live in `$XDG_STATE_HOME/rikka/emoji.json` (base emoji), written through `shell_kit::StateFile`.
- Settings: `skin-tone`, `type`.
- The grid is a fixed-column `list` up to eight rows. The field uses `leaves_arrows`, and Tab walks categories.
