- `src/effect/builtin/mod.rs` holds one `builtins!` table row per effect (name, title, `EffectFamily`, scene/display referral, constructor, one-sentence doc); it generates `BuiltinEffect`, `ALL`, `name()`, `title()`, `doc()`, `family()`, `effect()`, `is_display_referred()`. A new effect is one row plus its constructor; rikka-shader-compile turns every row into an `effect.<name>` composite node (title, doc, category from the family, image sockets beyond `image`, parameter ports with angle hints).
- Constructors live in `blur.rs`, `camera.rs`, `color.rs`, `detail.rs`, `distort.rs`, `glare.rs`, `layers.rs`, `stylize.rs`, `time.rs` with helpers `single`/`pass`/`step`/`target`/`socket` in `mod.rs`.
- Shaders: one program per step in `shaders/effects/<effect>[_<step>].slang`; parameters and algorithms in `shaders/lib/rikka/effects/<effect>.slang`. Shared modules: `blur` (linear-tap Gaussian, `RikkaBlurPush<P : IBlurParameters>.spread`), `bloom`, `screen`, `pyramid` (Burt–Adelson `[1 3 3 1]` reduce, per-level variance, cubic B-spline reconstruction clamped to a sub-rectangle, region-clamped separable Gaussian, `rikka_pyramid_plan` and `rikka_pyramid_varied`), `glare` (Karis-weighted EV bright pass, LOD ray gather `rikka_glare_rays`), `log_curves` (ACEScct, ARRI LogC3 EI800). `effects/pyramid_reduce.slang` has no parameter block, so any effect can use it (steps without a block are allowed). All steps of one effect share one `Parameters` layout.
- Optional sockets: `Effect::optional(name)` (e.g. `size`, `aperture`); an unwired one reaches the shader as `RIKKA_NONE`. Kept targets: `EffectTarget::kept()` survives to the next frame, read back with `EffectInput::Kept(name)` (first input on fresh history); frame_blend keeps its last input this way.
- Placement: scene-referred effects go before the Tonemap node, display-referred ones after it (`is_display_referred`). Display values are sRGB-encoded premultiplied; colour parameters are linear.
- Resolution: everything runs at display resolution; lengths are "px at 1080p" scaled by `rikka_effect_scale` (height/1080); geometry inputs are nearest-upsampled (depth, layers) or decoded (normals, velocity). Uniform-per-frame values that cost much (gate weave motion) are computed by one thread into a 1×1 target (`Divided(1 << 16)`).
- Neutral settings cost a copy: every expensive step early-exits on its neutral parameter (radius/length/distance/amount 0, CDL identity, white balance 6504 K / 0, trails persistence 0, shutter 0) and the final step copies its input. `tests/look/filters.rs` checks each new effect is within 1 LSB there.
- Methods: gaussian_blur uses an 8-level Gaussian pyramid; a uniform radius picks the deepest level that leaves a residual σ ≥ 1 level texel, blurs separably there and reconstructs with a cubic B-spline, accounting every variance so σ is exact (`radius` is σ); a wired `size` image interpolates per pixel between B-spline reconstructions of the levels by variance (mip-mapped variable blur: a size-0 pixel is the source exactly, larger sizes gather their neighbours, up to ≈195 display px). bokeh_blur gathers concentric rings (polygon-mapped, area-weighted, mirrored) at half resolution from half/quarter/eighth levels chosen by radius, boosts highlights over an EV threshold before gathering, takes a custom kernel from `aperture` and the pixel's own radius from `size`. dilate_erode is grey dilation by an octagon (square ⊕ diamond, four separable passes) with a linear feather. median is McGuire's 3×3 network with an optional relative threshold. bilateral is separable, guided by colour, relative linear depth and normals. edge_detect: Sobel/Prewitt/Kirsch/Laplacian normalized so a unit step reads 1, on luminance, colour, log depth or normals. streaks and lens_flare's starburst gather `count` rays at quarter resolution with a `(1-u)^falloff` profile and LOD by tap spacing; fog_glow weights pyramid levels by σ^(2−p) (a power-law PSF as a sum of Gaussians, Spencer 1995), folded at half resolution; lens_flare follows Chapman's pseudo flare (mirrored ghosts with per-channel shift, halo ring) on a Karis-filtered bright pass, so it has no temporal noise; halation spreads the red channel of highlights through the pyramid and adds it tinted red-orange. gate_weave combines low-frequency fbm drift and per-film-frame jitter with Catmull-Rom resampling and per-frame flicker. white_balance adapts the light's chromaticity (Krystek Planckian locus + Duv, offset so 6504 K/0 is D65) to D65 with Bradford; cdl follows ASC CDL 1.2 (Rec.709 luma saturation) linear or in ACEScct. lens_distortion's dispersion sums eight fixed wavelengths, so it never jitters. film_grain is smoothed lattice noise sized in display space, mono or colour, with a midtone (4L(1−L)) response.
- color_lookup reads 3D tables (`size²×size`, tetrahedral) or a strip of height 1 (per-channel linear 1D), shapers direct/srgb/log/acescct/logc3, `output` shaper (unshape) or display (keep). .cube 1D files are not parsed (rikka-color-lookup rejects `LUT_1D_SIZE`).
- Time effects (trails, frame_blend, datamosh) are neutral on a first frame (no history). Time-driven effects are deterministic in `frame.time` and `seed`.
- HDR thresholds are EV over middle grey of their input with a soft knee in EV, so after an Exposure node defaults work in daylight and lamp light alike.
- Cost at 1920×1080 (RTX 4060), defaults: kuwahara ≈2.6–4 ms, bokeh_blur 1.1–1.2 (radius 24), bilateral 1.0, sketch 0.75, outline 0.6 (+0.2 normals decode), lens_flare 0.5, heat 0.45, edge_detect 0.2–0.4, radial_blur 0.4, directional_blur 0.4, dilate_erode 0.4, gaussian_blur 0.34 (any radius), unsharp_mask 0.33, streaks 0.32, lens_dirt 0.27, fog_glow 0.27, halation 0.2, film_grain 0.13, gate_weave 0.13, frame_blend/datamosh/median/trails 0.11–0.12, layer/emission bloom ≈0.1 each, single-pass colour effects (cdl, white_balance, hsl…) 50–100 µs.
- `benchmarks/render` "three: every built-in effect at 1080p" (and upscaled from 67%) chains all of them around the standard chain, wires every `size` socket to the occlusion layer, tone-maps with half hue preservation and asserts zero steady allocations. Timed passes per frame are capped at 128, so per-effect timings of the whole chain cover only the earlier effects; time a subset to measure the rest.
