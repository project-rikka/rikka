---
title: Shared editable figures (rikka-figure)
description: rikka-figure is the UI-free figure model, vector text and imaging recipe; rikka-figure-editing edits it on canvas.
about: crates/graphics/rikka-figure
tags: [graphics, figures]
---

- Two public crates: the model `crates/graphics/rikka-figure` (deps: types, image-edit, text) and `crates/ui/rikka-figure-editing` (overlay painting, on-canvas typing, lettering controls, the `figure.*` catalog). `paint-document`, `paint-assistant`, `cut-project` and `cut-render` take only the model.
- Model: `Form { Line, Arrow, Shape { shape, frame, look }, Path(PathMark), Text(Lettering) }` in absolute units; `Shape { Rectangle { radius }, Ellipse, Triangle, Polygon, Star }` builds its imaging `Path` inside a `Frame` (centre, size, clockwise angle); `Look { fill, outline: Option<Pen> }` (`mark(path)` makes its `PathMark`); `Affine` is its own f64 2D map (convert psd maps with `from_array(to_array())`).
- Text: `Lettering` adds letter spacing, line spacing, up to two outlines, `Shadow` and `Band`; `Typeset` lays it (`hit` answers a `TextHit { at, affinity }` that hosts pass to `place_cursor`; caret, hit, selection, measure) and `Form::bounds` covers every decoration. `Typeset::raster` is the CPU raster for live overlays only.
- `recipe(forms, CanvasTransform { scale, offset })` turns forms into imaging steps: shapes as `Marks`; text through `Letterforms` at rest: vector glyph outlines (`GlyphRaster::outline`) filled over its outline strokes, band below, shadow as a blurred silhouette inside an imaging `Group`; colour emoji fall back to `Stamp`s.
- `Letterforms::new(lettering, scale)` traces each letter (non-whitespace char, in text order) once; `bounds(poses)` (px at `scale()`, divide for lettering units) and `recipe(poses, offset)` draw them with per-letter `LetterPose { offset, zoom, rotation (clockwise, about the letter centre), opacity, blur, wipe: Option<LetterWipe { from, progress }> }` in lettering units.
- Posed drawing groups letters into units: one sharp unit (sharing paths per opacity, with the band below), one blurred `Group` per 2^¼ blur step, and one `Group` per wiping letter, masked by the wipe polygon so fill and outline are cut as one silhouette. Shadows reuse the units (shade × letter opacity, blur = hypot(shadow, letter)) inside one group with the shadow's opacity. Colour emoji stamps are rasterised at the letter's zoom and rotated on the CPU, so they turn, blur, fade and wipe with their letter.
- The band is one box: at rest the layout box plus padding; while posed its edges move by how far the shown letters' union moved from the rest union (typewriter shrinks it, offsets stretch it), with the strongest letter opacity, and it disappears when no letter shows.
- Manipulation works on `Grips` (`Ends` or a `Frame` with optional side grips and turn knob), not on forms: `Manipulation::drag_to(at, Keys)` answers `ManipulationResult::Mapped { map, grips }` or `ManipulationResult::Ended`, and each app applies it to its own objects (Paint figures, Cut graphics). `Grips::around` merges several selections, `bounds`/`outline`/`cursor(grip)` serve snapping, member outlines and resize cursors, and `constrained_span(kind, anchor, at, Keys)` is the shared draw-drag rule (Shift aims lines and squares shapes, Alt centres shapes only).
- In rikka-figure-editing: `paint_grips`, `paint_loop`, `paint_line`, `paint_band` draw the selection overlay; `paint_dashed(points, closed, &[(length, colour)])` draws a repeating dash pattern (transparent runs are gaps); `paint_typing(typeset of the shown text, document, map)` draws selection, IME preedit underline and caret through any point map (projections may answer `None`) and returns the caret rect. On-canvas typing is one dispatch both apps call for every key, command, preedit/commit and focus-loss event while a text draft is open: `Typing::new(&document, &mut context_menu).caret(caret_rect).handle(event, || typeset, ctx)` answers `TypingOutcome` (`Edited` only when the document changed, `Unchanged` when handled without a change, `Committed`/`Dropped` for the host to end the draft, `Ignored` to fall through); the context-menu command opens `text_menu` under the caret; keys go through `rikka_ui::text::KeyEdit` after Escape, keypad/Ctrl+Enter commit and typeset-based Up/Down; Paste reads the clipboard asynchronously and inserts when it arrives (hosts repaint through the document's observers); clipboard, undo, delete and select all arrive as standard commands, never letter chords. `text_with_preedit` gives the shown text.
- Lettering controls: `font_choice::<Host>(font, set)` (installed families as cached labels) and `align_choice::<Host>(align, set)`; strings are `figure.*` in its own `locales/`, so hosts using them add `rikka_figure_editing::CATALOGS` with `I18nBuilder::embedded`.
- Future effects belong in imaging `Recipe`s appended to a figure's steps, so both apps share them.
