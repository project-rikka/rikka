- GPU-free, UI-free crate under rikka-animate; builds for Linux and Windows. The binary wires it; the thumbnail renderer is animate-booth.
- `Shelf::{Models, Motions, Cameras, Stages, Accessories, Music}` (`ALL`, `folder()`, `Choice` slugs) names the fixed subfolders; `Shelf::from_folder` also takes singular and MMD `UserFile` names (`Model`, `Motion`, `Camera`, `Accessory`, `BackGround`/`Stage`, `Wave`/`Sound`), case-insensitively. `Shelf::accepts(Format)` is the per-shelf format table.
- `Locations` = one home library (`standard()`: `<Documents>/Animate` on Linux, `<exe folder>/Library` on Windows) plus extra `Location { root, layout: Layout::{Library, Shelf(shelf)} }`; `ensure()` creates only the home root and shelf folders that no alias already provides. `Layout::slug/from_slug` is the stored form (animate-preferences `library-locations`).
- Files sit in shelves recursively (depth 8, 100k files, symlinks followed once, dot-names skipped); any known Animate format is listed, so a PMX in Motions shows as `Fit::Mismatch(Mismatch::Belongs(Models))`. Images are never entries; texture-only folders yield no folder chip.
- `Entry` (immutable, shared as `Arc<Entry>`): `EntryId::from_path`, path, shelf, folder (relative, `/`-joined, "" at top), name (stem), `Format`, size, modified, sidecar picture, `Details`, `Fit`. Fit is judged from shelf + format + details (`Unknown` while pending or unreadable).
- `Details::{Pending, Model, Motion, Sound, Unreadable(reason)}`; `Details::read(path, format)` is the bounded probe (own header readers for PMX, VMD, glTF/GLB/VRM/VRMA JSON, STL, Blend magic; `.rmotion` through `animate_document::Motion::load`; sound via rikka-media-format + rikka-audio-tags; FBX through a full `rikka_model` import, cancellable, one at a time, ranked last). VRM licence fields reuse `rikka_model::vrm::{Meta, LegacyLicense}`. `.rmotion` kinds other than figure/camera are `Mismatch::Unsupported`.
- Preferences live in animate-preferences `library.rs`: `library_locations`/`keep_library_locations` (extra locations as `{path, layout slug}`), `library_shelf` (state), `thumbnail_size` (`ThumbnailSize` from this crate).
- `Library::open(locations, sink)` runs `rikka-animate-library` (scan, watch with `Reach::Tree`, debounce `SETTLE` capped by `LONGEST_SETTLE`, `Lost` rescans) and up to 4 `rikka-animate-probe` workers ranked by cost, folder depth, size; `sink(Arc<Catalog>)` is called on the worker at most every `PUBLISH_INTERVAL`. `set_locations`/`rescan` re-watch and rescan; drop stops everything.
- `Catalog::shelf(s)` gives entries sorted by folder then natural name and `folders()`; `within(folder)` includes subfolders; `entry(id)`, `pending()`, `unavailable()` (missing roots).
- `Thumbnails` (`standard()` = `<cache>/rikka/animate/thumbnails`, or `new(dir)`): `thumbnail(entry, Variant)` answers `Ready(path)` (sidecar `<stem>.png/jpg/jpeg/webp`, a lone model's `preview.png`/`thumbnail.png`, the extracted embedded picture, or a stored render), `Pending`, `Extract` (call `extract` off the UI thread: VRM thumbnail or audio cover, fitted to `SIDE`), `Render` (call `store`) or `Missing`. Files are `<fnv(path, size, mtime, variant)>.png`, so a changed source misses; `Variant::Performed(FigureKey::from_file(figure))` keys motion renders by figure. The cache trims least recently touched files past 256 MiB.
- `animate-library-browser` is the left sidebar (`library(Desk)`, `WIDTH`), over the object-safe `Shelving` trait the binary implements (`src/animate/library.rs`, state `Shelves`); UI state is `Browser` (shelf, search `TextDocument` → lowercase terms, folder chip, `ThumbnailSize`, popup, hover preview `Feed`, lifted entry). It depends on no GPU crate: renders arrive through the `Painter` trait (`paint(entry, variant) -> Painting` future of RGBA), bridged in the binary to animate-booth by `src/animate/booth.rs` (`BoothPainter`, figure `Performer`s registered by `FigureKey`).
- Cards fetch thumbnails with `rikka_ui::fetch` keyed by (id, size, mtime, variant, usable), so only built (visible) cells request and scrolled-away ones are dropped; the grid memoizes cells by entry `Arc` pointer, tile, preview and variant. Hovering a Motions/Cameras card for `PREVIEW_DELAY` starts a booth live preview into a `Feed`.
- Motion thumbnails use `Variant::Performed` of the performer: the chosen figure, else the last chosen figure still present, else the mannequin (`Variant::Still`).
- Views do no file IO: `Browser::shown` memoizes the filtered list per (catalog `Arc`, shelf, folder, terms), and shelf folders come from `Locations::shelf_folder`, resolved once when the binary opens the library (`Shelving::shelf_folder`). The header spins while `Catalog::pending() > 0`; missing extra folders (`Catalog::unavailable`) carry a warning icon in Remove Folder. The binary keeps one performer key and the booth bridge one `Performer`, never a per-figure map.
- A click only selects a card (`Browser::select`, accent frame); loading is explicit: the sidebar footer's Load button, the card's context menu Load, or a drag of the card dropped on the window (recognised by `DragOffer::is_ours` plus the lifted entry). Double-click and Enter do not load (Enter is Register). `Shelving::take` routes by shelf: Models → figure, Motions → the chosen figure/prop, else the performer (made the subject), Cameras → makes Camera the subject then loads, Stages → `place_stage`, Accessories → `add_accessory`, Music → soundtrack. View → Library / Ctrl+L / the bar's first button toggle the sidebar.
