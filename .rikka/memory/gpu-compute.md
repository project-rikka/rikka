- Compute (`compute/`): `GpuBuilder::compute_support()` enables it when the device can (`vulkanMemoryModel` + device scope, `shaderInt64` for device-address arithmetic, buffer device address; a device lacking one logs what is missing and `Gpu::compute()` fails with `NotEnabled(Compute)`); `Gpu::compute()` gives a `Compute` (`Clone + Send + Sync`) with its own bindless table (sampled + storage images, GENERAL layout). It has two lanes, each with its own timeline: the front lane submits on the graphics queue; `compute.background()` submits on a dedicated async-compute queue (own family, else a lower-priority graphics-family queue, else the graphics queue; `is_async()` tells). Resources are CONCURRENT across the two families, track per-lane last uses, and a batch waits on the other lane's timeline when it touches what that lane last used. `images(&extents, ImageFormat)` hands out contiguous slots; `Batch` records dispatches (direct or `Dispatch::indirect`, groups checked against `widest_launch()`), uploads/copies/clears/ranged fills/buffer copies/ranged downloads, inserts global barriers between conflicting declared accesses and submits once into a `Ticket`. Each command buffer begins with a COMPUTE|TRANSFER barrier only (never drains graphics) and ends with a HOST barrier only when it downloads; consumers must wait on the `Ticket`. Recording happens outside the context lock on per-lane recorders; staging and download buffers are pooled; identical SPIR-V shares one `Kernel`. `Ticket::is_ready`/`Download::is_ready` poll without blocking. `Batch::scope(name)` marks a timestamp and `timing()` returns a `Timing` whose `wait()` yields per-scope `Span`s. Shaders bind set 0 and ≤128 push bytes, buffers by device address.
- Compute can lend outside images: `Compute::import_dmabuf(&DmabufSpec)` (sampled slot, acquired from and released to the foreign queue every batch) and `Compute::video_target(VideoTarget)` (storage slot per plane over a caller's video frame, with its waits, signals and old layout, written by one batch only); dispatches name them with `reads_foreign`/`writes_foreign`.
- Compute images (`compute/image.rs`): a `ComputeImage` is a GPU image body (pixels, id, layout, last uses) bound to one slot of a contiguous slot run. `images(&extents, format)` makes fresh bodies; `tiles(&[ComputeTile::New(extent) | ComputeTile::Reuse(&image)], format)` binds a new run in which kept entries share an existing body (copy-on-write versions of imaging planes), so `aliases`/`pixels_id` tell identical pixels. A run frees its slots once its last use finished; a body goes to the pool when its last handle drops. `Batch` holds every bound handle it touches, keyed by slot, and tracks hazards per body.
- Compute recycling (`compute/pool.rs`): dropped image bodies (layout kept) and submitted staging buffers go to a bounded pool (1 GiB / 1024 images, 256 MiB staging, 2 s idle trim on each submit); a new image reuses a body of the same format and extent only once its work finished. `Compute::trim()` returns idle command-buffer memory, for long-lived workers to call when they go quiet (Paint's document worker and Cut's render thread do after 3 s). `Batch::upload_rows(image, origin, extent, bytes, stride)` stages strided rows with one copy.
- Computed pictures reach the screen without readback: `Uploads::create_compute_target(w, h)` makes a picture texture (mips grow on demand) and `copy_computed(id, at, ComputedCopy)` copies an Rgba8 premultiplied compute image in the next frame's setup batch, which waits on the compute timeline and keeps the image alive until the frame retires. `ComputedFrame` is a picture made of such parts; `area(origin, extent)` cuts a sub-frame without GPU work; `is_ready()` polls its tickets and `on_ready(notify)` calls `notify` once all of them completed.
- Completion callbacks (`compute/completion.rs`): `Ticket::on_ready` / `ComputedFrame::on_ready` run `notify` at once when already reached, otherwise on the lazily started `rikka-compute-completion` thread, which waits (`vkWaitSemaphores` ANY) on both lane timelines plus a host-signalled wake semaphore bumped by each registration. A failed wait (device loss) releases every waiter; `notify` must re-check `is_ready` or wait to see the error. `FrameTimeline::finished()` is a `Result`.
