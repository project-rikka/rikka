- API: `ViewportConfig::antialiasing(Antialiasing::{Multisample, Temporal, Upscale(Upscale)})`. `samples` applies to Multisample and Temporal (TAA over MSAA); Upscale renders single-sampled. `Upscale::fixed(scale)` / `Upscale::dynamic(target)` (`RenderScale::Dynamic(DynamicScale { target, min, max })`), `.sharpness(..)` (RCAS, 0 off). `Viewport::{render_size, render_scale, gpu_time, is_converging, antialiasing}`. `Frame::cut()` drops history (and zeroes motion for that frame); a cut on a frame identical to the last one is ignored.
- Viewport splits render targets (`Targets`: colour, depth, identity, outline, HZB, clusters, slots) from the display-sized output texture; they are allocated once at the capacity extent and drawn in a sub-rectangle at the render extent (see render-resolution.md); `Viewport::retarget` (start of `Record::frame`) only moves that extent when the dynamic controller picks a new scale. The controller (`scale.rs`) reads a per-viewport two-timestamp query ring (`timer.rs`, only for dynamic) and moves the scale in 1/32 steps after 12 settled frames.
- Jitter: Halton(2,3) offset in render pixels; `GpuView.view_projection`/inverses/`projection` are jittered (translation in clip space), `GpuView.jitter` is the NDC offset, `mip_bias` = log2(scale) − 1 is applied by `RikkaTexture::sampled` (SampleBias via `rikka_push`). Moving phases = 8 × (1/scale)², still frames walk Halton from index 2.
- Motion vectors everywhere are uv(now) − uv(before) over the render image, y down, jitter-free: vertex shaders output `rikka_unjittered(view, clip)` for velocity while rasterizing jittered (`lib/rikka/temporal.slang`: `rikka_unjittered`, `rikka_motion`, `rikka_sky_motion`, `rikka_point_motion`). Rigid motion comes from `RikkaFrame.previous_transforms` (per instance, `ViewHistory::previous_transforms`, keyed by mesh/index range/object id), deformation from `previous_positions`; fluid splats unjitter too. The surfaces pass runs whenever temporal is on; previous positions are kept for temporal or motion blur. Histories kept in jittered render space (denoisers, radiance) reproject with `rikka_history_uv`/`rikka_previous_image_uv`, using `RikkaView.previous_jitter`; `RikkaView.cut` marks a cut frame.
- Still detection: `record/mod.rs` `content_signature` hashes the view (unjittered), instances, lights, bones, morphs, `GpuLook`, `MaterialPool::revision` and the ticket values of drapes, wetness, fluids and frame waits; `TemporalState::advance` counts repeats. Repeated content accumulates as a true running average (no clipping, no reactive) up to 64/scale² frames, then settles: jitter stops and the resolve copies history, so paused frames are bit-identical. In-place texture rewrites are not in the hash. rikka-ui's viewport store re-renders the last frame while `is_converging`, so apps that return no new frame still converge.
- Resolve (`temporal_resolve.slang`, one compute pass, display-sized): closest-depth 3×3 dilation (5×5 on outline pixels), Catmull-Rom history, YCoCg variance clip (moving only), exposure-aware reversible tone (knee 1 for filmic tones, 0.25 for clamp; exposure from last frame's meter of the composite's first reachable Exposure node, knee from its first Tonemap; frame exposure and the linear knee without them), per-pixel accumulated weight in a meta history (x weight, y lock, z luma, w lock luma), disocclusion against last frame's scene depth (min of 2×2), reactive = |blended − opaque| (opaque copy forced before transparents/particles/grid/overlays, or the pre-fluid image), thin-feature locks, flicker damping, outline mask = shaded depth (incl. hulls) closer than G-buffer depth → fewer history frames while moving. Native uses the pixel's own sample; upscale uses a render-unit Gaussian while moving and a display-pixel box once confident in still frames.
- Histories use the graph's ping-pong keeps `ImageSpec::current(key)` / `previous(key)` (bound by `ViewGraph`'s turn), so the graph signature stays constant; effect history uses them too.
- Order: shade → fluid → reflections, lines, fog → temporal resolve → RCAS → (display res) the compositor graph and present. `FrameGraph::enter_display` makes later `Size::Viewport`/`Divided` images display-sized; display passes read `SceneImages::post` (dilated depth R32F + motion) and map render-res identity/outline masks by `ratio`; effects get upsampled layers (`effect_layers.slang`) and decoded normals.
- The resolve reads its closest-depth window and disocclusion depths with `GatherRed` (`closest_depth<REACH>` unrolls the 3×3/5×5 window from 4/9 gathers in raster order, so the chosen pixel matches per-texel loads exactly).
- Tests: `tests/three/temporal.rs` (convergence vs 4×4 supersample, ghosting, cut, outline crispness, settled stability, dynamic scale, scale steps), `tests/look/effects.rs` (layer tint upscaled). Bench scenarios `three: look frame, temporal antialiasing` / `upscaled from 67%` / `ray traced look frame at 1080p, dynamic resolution stepping down`.
