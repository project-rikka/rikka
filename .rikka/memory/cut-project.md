- `cut-project` (UI-free; uses `rikka-figure`, `rikka-effects`, `rikka_image_edit::Path` and `rikka-types`) owns the model: `Rate`, drop-frame `Timecode` (`from_frame`, `parse`), `Media` (`Stream::{Picture, Sound}`), `Project` with positional `Layer`s (index = "レイヤー NN", higher index drawn in front; layers grow on demand via `layer_mut`), clips whose `Source` is `Footage { media, source_in, treatment }` (carrying their own sound; `Treatment` = placement, corner radius, `Mirror`, speed 10–400% that maps timeline to source frames via `source_at`/`source_position`/`origin`, and `Mix`), `Graphic(Arc<Graphic>)`, `Camera(Arc<Camera>)` (a 2.5D camera, see cut-animation note) or `Region(Arc<Region>)` (an effect range: `Placement` + `Area::{Whole, Shape { shape, width, height }}` + feather px + inverted; `Region::path(format)` is its figure `Path` in project px, rectangle radius × zoom; `Whole` has no grips/bounds/path and never hits); graphics are (`Graphic { placement: Placement { x, y from the frame centre, depth, anchor, zoom, aspect, rotation, tilt_x, tilt_y, opacity, three_d }, art: Art::{Shape, Line, Text { lettering, reveal }} }` in local, centred, unzoomed units; `frame`/`grips`/`hits`/`mapped`/`ended` convert stage manipulations back into placement and size), one id counter, `Visual` (graphic, region, or footage with its picture fitted into the format; `grips`/`bounds` are `None` for a whole-frame region) gives the stage one geometry; `Edit::Redraw { changes: (ClipId, Appearance), by, at }` restyles graphics, regions or footage, and a changed speed re-lengths the clip within media and its neighbour; `Edit` → pure `Project::apply`, `Document` (Arc snapshots, undo/redo, revision-based modified flag; `amend` folds an edit into the last undo step), `Piece` clipboard copies, `Snap`, JSON `.rcut` (`JsonFormat` `rikka-cut` v1: project-relative media paths, layer heights, keyframes, cameras, animation presets, transitions, markers; load failures are `Error::File`, validation failures `Error::Damaged`).
- Layer heights: `Height` (whole px, `RANGE` 28–240, `SMALL`/`MEDIUM`/`LARGE` presets) as `Project::layer_height` (default) plus an optional per-layer override; `Project::height_of(index)` resolves either, spare rows included. `Edit::Resize { layer, height }` sets one override (locked layers too), `Edit::ResizeAll(height)` sets the default and clears every override; both are undoable `Action::Resize`.
- `Project.layers` is `Vec<Arc<Layer>>`: `Project::apply` clones shallowly and only touched layers are copied (`layer_mut` = `Arc::make_mut`, `normalize_transitions` and ripple delete skip layers they would not change), so undo snapshots and slider previews share unchanged layers and `Project` equality short-circuits on shared layers. The stage memoizes its `Item`s per (shown project, frame, viewpoint, overrides) in `ItemCache`.
- Animation, effects and animation presets live on `Clip` (not the source): a private `Motion` map of placement/art/camera tracks, `effects: Vec<EffectSlot { effect, enabled, tracks: BTreeMap<knob key, Track<Scalar>> }>` and `animation_presets: AnimationPresets`; the keyframe model, keying edits, presets, projection and their file layout are mapped in the cut-animation note. Edits and queries take timeline frames (`Clip::local` clamps). `Project::visual(clip, frame)`/`visuals_at(frame)` give keyed values (what the stage edits); `Project::shots_restyled(frame, Viewpoint, overrides)` gives presented values plus projection in draw order. Redraws and retunes key animated values that changed at their frame and change base values otherwise.
- Edit rules: `Place` puts files one after another from a frame on the first free layer at or below the asked one; `Paste` keeps relative layers/offsets and drops the band to the first free layers (never overwrites); `Move` overwrites (carves) what it lands on; `Trim`/`Slip` stay within media and neighbours; ripple delete closes a gap only when every unlocked layer is clear there; locked layers refuse edits and are skipped when placing. `Insert { item: Item::{Graphic, Region} }` puts an item on the first free layer at or above `front_layer(frame)` (one above whatever shows there); `Redraw { graphics, by }` replaces graphics in one undo step; graphics trim freely and never slip.
