- Textures go through `Uploads` (`renderer.uploads()`, `Clone + Send + Sync`): create/blank/import/update/destroy/video frames validate against a shared texture book, make the image and reserve its bindless slot on the calling thread, and queue the rest. `reclaim()` (every `start`/`draw`) drains the queue. `renderer.textures()` is a guard that derefs to `Uploads` and drains the queue when it drops, for single-thread owners like the compositor; a guard held in a `let` must drop before the renderer is borrowed again. `create(Pixels)` and `update_region(id, offset, Pixels)` take a `Pixels` (extent, format, data; `Pixels::rgba8/premultiplied/srgb`).
- Rows in a DRM layout: `Uploads::supports_drm_format(fourcc)` / `create_drm(fourcc, w, h)` make a texture of that Vulkan format (8888, 2101010, 16161616F, 565 from `drm::texture_format`; X formats get an alpha-one view), and `stage(id, Rows::new(pixels, stride), &[TexelRect])` copies each rect once into the shared upload ring (`texture/ring.rs`: persistently mapped blocks, spans retire on the frame or transfer timeline, freed at `trim()`); the returned `Staged` must be `send()`ed, dropping it discards (a faulted SIGBUS read). Only textures listed with `texel_bytes` (not straight `Rgba8`) take rows.
- Planar dmabufs (`drm/planar.rs`) are converted once per commit by `YcbcrConverter` with the `Ycbcr { matrix: Bt601|Bt709|Bt2020, range, siting }` given to `Uploads::import_ycbcr_dmabuf` (`import_dmabuf` uses `Ycbcr::guessed(height)`); chroma siting offsets the chroma sample by ±¼ chroma texel on subsampled axes, and sources deeper than 8 bits convert into RGBA16F (second pipeline built on first use). Render (scan-out) and export formats include XR30/AR30/XB30/AB30 after the 8-bit ones.
- One update-after-bind descriptor set serves every shader. fx passes and YCbCr conversion read it through push-constant indices. A stale slot draws magenta. One timeline governs frame slots, deferred destruction, atlas eviction and readback.
- Bindless-table images end in `ImageAccess::TABLE_SAMPLED` (vertex, fragment and compute). Client dmabufs are acquired from FOREIGN (GENERAL) only for frames that draw them, and released at frame end.
- Picture textures (`create`, `create_compute_target`) start with one level. Emitting an image node drawn at under 1/1.25 of its sampled texels (`ImageSource::minifies`, not pixelated) asks the `TextureBook` (`drawn_minified`); under the renderer lock (`take_uploads`, and in `Painter::frame` right after preparing) `TexturePool::grow_minified` makes a mipped image in a new slot, relists it (`TextureBook::moved`), copies the old level 0 and builds the chain in that frame's setup batch, and retires the old image and slot. A prepared scene re-prepares when a texture moved after its preparation (`PreparedBatch::book_revision`), so no batch draws a released slot. Textures a material binds grow at `create_material` (material records keep slots). `Mips::Fixed` listings (canvas, imported, unblittable, 1 px) never grow.
- Textures: premultiplied RGBA8, straight (premultiplied on upload), `Rgba8Srgb`, or linear float `Rgba16Float`/`Rgba32Float` (`Pixels::rgba16f`/`rgba32f` from RGBA `f32` samples; 32-bit float ones never grow mips where linear blits are unsupported, and readers that must not depend on linear filtering load texels). `update_region` refuses pixels whose texel size differs from the texture's. `textures().blank()` is GPU-cleared.
